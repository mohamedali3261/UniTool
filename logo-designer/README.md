# مصمم الشعارات — UniTool Logo Designer

صفحة مستقلة على **`/logo-designer/`**، مبنية بـ React وSVG. كل كود الصفحة وأصولها وخطوطها واختباراتها في هذا المجلد؛ ملفا الإعداد العام يضيفان مدخل Vite ورابط التنقل فقط. لا تحتاج مفتاح API أو حسابًا.

## تشغيل واختبار

من جذر UniTool:

```bash
npm ci
npm run dev
# افتح http://localhost:3000/logo-designer/
npm run lint
npm run build
npm run test:logo-designer
npm run test:logo-designer:browser
```

اختبارات المتصفح تستخدم Chromium الخاص بـPlaywright. ثبّته بـ `npx playwright install chromium`، أو مرّر `STUDIO_CHROMIUM_PATH` لمسار نسخة متاحة. البناء ينتج `dist/logo-designer/index.html`؛ انشر **كل** `dist/` مع الملفات المشتركة، لا هذا الملف وحده.

## النواة المشتركة

- `types.ts`: نموذج المشروع والعنصر. الإحداثيات بوحدات اللوحة، وموقع العنصر هو **مركزه**.
- `state.tsx`: مصدر الحقيقة لكل الأقسام؛ سجل تراجع 40 خطوة. `begin/live/end` يجعل السحب خطوة واحدة. `commit` لتغيير المشروع، `patch` للمحدد غير المقفول، و`add` لإنشاء عناصر جديدة بمعرّفات مستقلة.
- `render.tsx`: نفس مرسم SVG للوحة والقوالب والنماذج والتصدير، بما فيه النص العربي والتأثيرات. التصدير لا يصور واجهة البرنامج.
- `catalog.ts` و`templates.ts`: مكتبة الرموز والأشكال واللوحات وتعريفات القوالب.
- `storage.ts`: IndexedDB، حفظ تلقائي بعد 900ms من التغيير، والتحقق من JSON المستورد. حد المشروع 500 عنصر. لا يسمح بصور ذات روابط خارجية أو SVG تنفيذي مستورد.
- `fonts.ts` و`assets/`: 14 عائلة خطوط محلية بأوزان حقيقية ونطاقات Unicode وتراخيصها. SVG يضمّن الخطوط المستخدمة وخط Cairo الاحتياطي للنص العربي؛ بعض برامج المتجهات قد لا تدعم خطوط SVG المضمّنة، فثبّت العائلات محليًا عند التحرير فيها.
- `image-tools.ts`: إزالة الخلفية المتصلة بالحواف وحساب مسارات التحويل البسيط.
- `export-tools.ts`: SVG محمول، تحويله إلى Canvas، التنزيل، وأشكال حزمة العلامة.

## إضافة محتوى أو قسم

1. **رمز:** استورده صراحةً من Lucide في `catalog.ts` وأضفه إلى المجموعة المناسبة؛ المكتبة والمرسم يقرآن السجل نفسه. لإضافة شكل هندسي جديد، أضف اسمه إلى `shapes` وارسمه في `ElementGraphic`.
2. **قالب:** أضف تعريفًا في `templates.ts` أو تركيبًا جديدًا في `templateProject`. أنشئ كل جزء بـ `node()`؛ لا تستخدم صورة مسطحة للقالب.
3. **قسم:** أنشئ ملفًا بجانب الأقسام، استخدم `useDesigner()` للحالة و`t(ar,en)` للنصوص، وسجله في قائمة `tabs` داخل `App.tsx`. لا تحتفظ بنسخة منفصلة من المشروع داخل القسم.
4. **خاصية عنصر:** أضفها إلى `types.ts` والقيمة الافتراضية في `node()`، والتحقق في `storage.ts` إن كانت مطلوبة، ثم المرسم والواجهة واختبارًا. اجعل الخصائص الجديدة اختيارية أو وفّر ترحيلًا لمشاريع الإصدار 1 القديمة.
5. **خط:** ضمّن WOFF2 والترخيص تحت `assets/`، ثم أضفه إلى `fonts.json` مع نطاقات Unicode الصحيحة وأسماء ملفات الوزن؛ لا تعتمد على CDN.

## حدود واضحة وخصوصية

- المساعد **اقتراحات محلية قائمة على قواعد وقوالب**، وليس توليد صور بالذكاء الاصطناعي عبر خدمة خارجية.
- إزالة الخلفية تستهدف لونًا متصلًا بالحواف، وليست قصّ أشخاص أو شعر. المعالجة على نسخة بحد أقصى 1024px؛ التحويل المتجهي يكمّم الألوان ويتتبّع شرائط عند 128px، لذا يناسب الشعارات البسيطة ولا يدّعي تتبّع صور فوتوغرافية احترافيًا.
- النماذج توضيحية CSS/SVG وليست تصويرًا واقعيًا. التصدير يصدّر **الشعار**؛ لا يصدر مشهد النموذج نفسه.
- SVG متجهي بخطوط مضمّنة، PNG يدعم الشفافية، JPG بخلفية بيضاء عند الحاجة. PDF يحتوي صورة عالية الدقة داخل مستند، **وليس PDF بمسارات متجهة**. أبعاد الصور حتى 4096px لكل ضلع، والأبعاد المخصصة قد تمدّ النسبة؛ المقاسات الجاهزة تحافظ عليها.
- ZIP يتضمن SVG وPNG وSVG أحادي اللون وfavicon PNG 64px وصورة حساب 512px ونسخ SVG أفقية ورأسية وJSON. النسخ الأفقية والرأسية تعيد ترتيب مجموعة النص بجوار/أسفل مجموعة الرمز؛ راجع تباعد التصاميم المعقدة قبل النشر.
- المشاريع والصور والألوان محفوظة **في هذا المتصفح فقط**؛ لا مزامنة سحابية. تنزيل JSON هو النسخة الاحتياطية القابلة للنقل. مسح بيانات المتصفح يحذف التخزين المحلي.
- الحذف يطلب التأكيد. الحفظ له حالات انتظار ونجاح وفشل. النوافذ تستخدم `dialog` لنقل التركيز وحبسه واستعادته، وأزرار الأيقونات مسمّاة لقارئات الشاشة.

## توسعة المكتبة وتحسينات الترتيب

- 24 قالبًا جديدًا فوق القوالب الأصلية، في ست عائلات مختلفة: ختم دائري، حرف مميز، تحريري، درع وشريط، جانبي، ومدارات. أصبح الإجمالي 60 قالبًا في تسع عائلات تكوين.
- `extended-templates.ts`: تعريفات التوسعة وتركيبها من طبقات مستقلة. لإضافة قالب جديد حدّد المجال والخط والرمز والعلامة والتكوين. يظل `templates.ts` واجهة الاستدعاء الموحدة.
- `extra-symbols.ts`: رموز مجالات الصحة والتعليم والسفر والمال والإنتاج والألعاب والصناعة.
- `vector-library.ts`: 28 علامة أصلية بمسارات متجهة آمنة، بما فيها زخارف ونباتات وحروف هندسية وإطارات. تعديل التعبئة والتدرج يعمل على نفس المسارات في التصدير.
- المكتبة تدعم فلترة النوع والتصنيف، والمفضلة وآخر 30 عنصرًا مستخدمًا. تُحفظ هذه التفضيلات محليًا بمعرّفات فقط عبر `library-preferences.ts`.
- القوالب قابلة للبحث والفلترة حسب التكوين والمجال، مع تجربة اسم نشاط مخصص على المعاينات قبل التطبيق. البحث العربي عبر `search.ts` يتجاهل التشكيل وأشكال الألف.
- `SelectionTools.tsx` و`selection-tools.ts`: محاذاة حواف ومراكز الاختيار، توزيع المسافات أفقيًا ورأسيًا لثلاثة عناصر أو أكثر، وإرسال مجموعة للأمام/الخلف. المقفول والمخفي مستثنيان، وكل عملية خطوة تراجع واحدة. المحاذاة تستخدم الغلاف المستطيل المرئي للعناصر المدورة؛ التأثيرات والظل والنص الخارج عن صندوقه لا تدخل هذا الغلاف.

## تركيبات الأيقونات القابلة للفك

من **العناصر ← تركيبات أيقونات قابلة للتعديل** تتاح 12 مجموعة: قلم ولمبة، ورقة وقطرات، بيت ومفتاح، كتاب وجناحين، قهوة وشمس، درع وحرف، عين وعدسة، حرف وسهم، جبال وبوصلة، قلب ونبتة، مدار وشرارة، وتاج وماسة.

- `compositions.ts` يعرّف الأجزاء كعناصر حقيقية، و`compositionNodes` ينشئ معرّفات ومجموعة مستقلة لكل إضافة ويضبط المقاس والموقع واللونين والحرف.
- `Combinations.tsx` يعرض المعاينات والبحث وضبط اللون والحرف والحجم، مع خيار الإضافة كمجموعة أو كأجزاء حرة. الإضافة لا تستبدل تصميمك الحالي، وتدخل التراجع كخطوة واحدة.
- `GroupParts.tsx` داخل الخصائص يتيح اختيار أي جزء لتعديل لونه ومقاسه ومكانه، مع تحديد المجموعة كاملة أو فكها. الأجزاء المقفولة لا تتغير. للتجميع مرة أخرى حدّد الأجزاء واستخدم **تجميع** من قسم الطبقات.
- التكوين ليس اتحاد مسارات Boolean ولا صورة مسطحة؛ تظل كل القطع قابلة للتحرير والحفظ والتصدير باستخدام النواة الحالية.

## قائمة الكليك اليمين والضغط المطوّل

- على اللوحة، كليك يمين بالماوس أو ضغطة لمس ثابتة لمدة 550ms لفتح قائمة مدمجة. الحركة أكثر من 8px أو اللمسة الثانية تلغي المؤقت حتى لا تتعارض مع السحب والتحريك والتكبير بإصبعين. رفع الإصبع أو إلغاء اللمس يلغي المؤقت أيضًا.
- الأوامر: قص، نسخ، لصق في مكان الضغط، تكرار، تجميع وفك تجميع، قفل وفتح القفل، للأمام والخلف، تحديد الكل، تراجع وإعادة، وحذف بعد التأكيد. الأوامر غير المتاحة تظهر معطلة؛ العناصر المقفولة لا تُقص أو تُحذف.
- الحافظة **داخل المحرر فقط**، وليست حافظة نظام التشغيل ولا استيراد صور/نصوص خارجية. تستمر خلال التنقل بين المشاريع في الجلسة الحالية، وتُمسح عند تحديث الصفحة. كل لصق ينشئ معرّفات ومجموعات جديدة ويحافظ على المسافات النسبية. القص واللصق يدعمان التراجع.
- الاختصارات: Ctrl/⌘ + C للنسخ، X للقص، V للصق، D للتكرار. لا تعترض اختصارات حقول الكتابة. Shift+F10 أو مفتاح قائمة السياق يفتح القائمة للعنصر ذي التركيز؛ الأسهم وHome/End تتنقل، وEscape أو النقر خارجها يغلقها. القائمة تضبط مكانها داخل الشاشة وتدعم العربية والمظهر الداكن.
- `ContextMenu.tsx`: واجهة القائمة وأوامرها وإدارة التركيز. `clipboard.ts`: نسخ العناصر وإنشاء معرّفات ومجموعات جديدة. `state.tsx`: حافظة الجلسة والأوامر المشتركة. `Canvas.tsx`: موضع القائمة ومؤقت اللمس وإلغاء الإيماءات المتعارضة.

## مجموعة إضافية وعرض الموبايل

- **80 قالبًا إجماليًا**: أضاف `collection-2026.ts` عشرين قالبًا في خمس عائلات جديدة: الأقواس، الفسيفساء، الكبسولة، المنارة، والتوقيع. كل جزء يظل عنصرًا مستقلًا، مع دعم اسم النشاط والألوان والتراجع والتصدير الحالي.
- `more-symbols.ts` يضيف **87 رمزًا مختلفًا** للأثاث والأجهزة المنزلية، السفر، الصناعة والطباعة، الطعام، الموسيقى والإبداع، الصحة، الطبيعة، الأعمال والرياضة. أصبح الإجمالي **295 عنصرًا مفردًا** (255 رمزًا + 12 شكلًا + 28 علامة أصلية)، بجانب تركيبات الأيقونات الـ12.
- حتى عرض 600px: التصميم يظهر أعلى مساحة العمل والأدوات في لوحة سفلية مستقلة لا تغطيه. التنقل في صف واحد قابل للسحب الأفقي بارتفاع 54px، مع مراعاة المنطقة الآمنة أسفل الهاتف. يمكن طي اللوحة أو توسيعها للتصفح الكامل، والخصائص لها زر إغلاق مباشر.
- في الوضع الأفقي الضيق تُعرض الأدوات بجوار اللوحة لتقليل الارتفاع المستهلك. النوافذ الأوسع/الأقصر على أجهزة اللمس لها توزيع جانبي بدل التغطية. الإيماءات والقائمة السياقية والحفظ والتصدير تظل مشتركة مع إصدار الكمبيوتر.
- احتواء اللوحة يقلل الهوامش في المساحات الضيقة ليبقى الشعار أوضح في المعاينة. القفز بين المقاسات لا يفتح المكتبة والخصائص معًا على شاشة ضيقة.

### وضع الموبايل المدمج: المعاينة أولًا

- شريط التنقل السفلي أصبح صفًا واحدًا بارتفاع 54px بدلًا من 112px، والأقسام الباقية متاحة بالسحب الأفقي. الأزرار تظل بارتفاع لمس 44px.
- لوحة المكتبة/الخصائص العادية أصبحت بين 148 و210px، وبحد أقصى 32% من مساحة العمل. زر التوسيع يظل متاحًا للتصفح الكامل، والإغلاق يعيد المعاينة حتى لو كانت اللوحة موسعة.
- الشريط العلوي 88px بدلًا من 108px، مع تقليل عناوين الأدوات والهوامش وإخفاء الوصف التقديمي في الوضع المضغوط فقط. القوالب والتركيبات في ثلاثة أعمدة عند التصغير وعمودين عند التوسيع.
- اختبارات الموبايل تتحقق من ارتفاع شريط التنقل واللوحات، وأن مساحة المعاينة أكبر بوضوح من مساحة لوحة الأدوات، مع بقاء كل الأقسام قابلة للوصول دون تمرير أفقي للصفحة نفسها.

### الوحدات والحدود الهندسية

- `path-engine.ts` يستخدم Paper.js (MIT) لعمليات المسارات الفعلية. يدعم الأشكال الممتلئة والعناصر المتجهة، وليس تفريغ Stroke تلقائيًا أو تحويل خطوط النص إلى outlines أو تتبّع الصور. الحلقات الخطية ورموز Lucide الخطية والنصوص والصور تُعطّل لها عمليات Boolean صراحة. النتيجة الفارغة لا تستبدل العناصر؛ العمليات الناجحة قابلة للتراجع، وتتبنّى مظهر أول عنصر.
- `PathTools.tsx` محرر نقاط ومنحنيات داخل الخصائص يعكس التعديلات فورًا على الشعار والتصدير. يحافظ على ثلاثة نقاط على الأقل للمحيط المغلق ونقطتين للمفتوح. SVG المتجهي يُرسم بتطبيع 128×128 مع `preserveAspectRatio="none"` للحفاظ على الأبعاد الصحيحة.
- `variants.ts` و`Variants.tsx`: لقطات بديلة مستقلة داخل المشروع، مع تحديث النسخة المغادرة قبل التبديل. الصور النقطية تحتفظ بألوانها؛ إعادة التلوين للمتجهات والنصوص. حد 8 نسخ و500 عنصر لكل نسخة، والتحقق من الاستيراد يشمل كل نسخة.
- `personal-assets.ts` و`PersonalLibrary.tsx`: قاعدة IndexedDB مستقلة `unitool-logo-personal-assets`، حتى 50 عنصرًا محفوظًا عبر الواجهة و12MB للعنصر. لا مزامنة سحابية؛ امسح بيانات المتصفح فتُحذف المكتبة أيضًا. يُعاد إنشاء المعرّفات والمجموعات عند الإدراج لتجنب التصادم.
- `QuickEdit.tsx` و`InlineTextEditor.tsx`: أدوات سريعة وكتابة مباشرة. `Readability.tsx` يعرض الأحجام الفعلية، و`brand-guide.ts` يرسم النص العربي بالخطوط المحلية قبل وضع الصفحات في PDF لضمان اتصال الحروف.
