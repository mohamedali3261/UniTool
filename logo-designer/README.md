# مصمم الشعارات — UniTool Logo Designer

صفحة مستقلة على **`/logo-designer/`**، مبنية بـ React وSVG. كل كود الصفحة وأصولها وخطوطها واختباراتها في هذا المجلد؛ ملفا الإعداد العام يضيفان مدخل Vite ورابط التنقل فقط. لا تحتاج مفتاح API أو حسابًا.

## تشغيل واختبار

من جذر UniTool:

```bash
npm ci
npm run dev
# افتح http://localhost:3000/logo-designer/
npm run lint
npm run build
npm run test:logo-designer
npm run test:logo-designer:browser
```

اختبارات المتصفح تستخدم Chromium الخاص بـPlaywright. ثبّته بـ `npx playwright install chromium`، أو مرّر `STUDIO_CHROMIUM_PATH` لمسار نسخة متاحة. البناء ينتج `dist/logo-designer/index.html`؛ انشر **كل** `dist/` مع الملفات المشتركة، لا هذا الملف وحده.

## الأقسام الأربعة عشر

| الملف                | المسؤولية                                                                      |

| `ShapeLibrary.tsx`   | البحث والتصنيفات وإضافة الأشكال والرموز المتجهة                                |

| `Colors.tsx`         | تعبئة وتدرج، لوحات ألوان، توليد من لون أساس ومفضلة محلية                       |
| `Templates.tsx`      | 36 تكوينًا أصليًا بعناصر مستقلة قابلة للتعديل                                  |
| `Layers.tsx`         | إظهار وقفل وتسمية وتجميع ونسخ وحذف وترتيب بالسحب أو الأزرار                    |
| `Properties.tsx`     | موضع ومقاس ودوران وشفافية وحدود وظل وتمويه وانعكاس وخلفية اللوحة               |
| `Upload.tsx`         | رفع PNG/JPG/WebP، إزالة خلفية بسيطة وتحويل إلى مسارات متجهة                    |
| `SmartAssistant.tsx` | اقتراحات محلية حسب الاسم والمجال واللون، يمكن تطبيقها وتعديلها                 |
| `Mockups.tsx`        | 7 نماذج توضيحية متجهة تتحدث مع المشروع ولون خامة قابل للتغيير                  |
| `Export.tsx`         | SVG وPNG وJPG وPDF وJSON وحزمة ZIP                                             |

`App.tsx` يجمع الأقسام، و`main.tsx` نقطة التشغيل، و`styles.css` تنسيق عام مستقل، متجاوب ويدعم RTL والمظهرين وتقليل الحركة.

## النواة المشتركة

- `types.ts`: نموذج المشروع والعنصر. الإحداثيات بوحدات اللوحة، وموقع العنصر هو **مركزه**.
- `state.tsx`: مصدر الحقيقة لكل الأقسام؛ سجل تراجع 40 خطوة. `begin/live/end` يجعل السحب خطوة واحدة. `commit` لتغيير المشروع، `patch` للمحدد غير المقفول، و`add` لإنشاء عناصر جديدة بمعرّفات مستقلة.
- `render.tsx`: نفس مرسم SVG للوحة والقوالب والنماذج والتصدير، بما فيه النص العربي والتأثيرات. التصدير لا يصور واجهة البرنامج.
- `catalog.ts` و`templates.ts`: مكتبة الرموز والأشكال واللوحات وتعريفات القوالب.
- `storage.ts`: IndexedDB، حفظ تلقائي بعد 900ms من التغيير، والتحقق من JSON المستورد. حد المشروع 500 عنصر. لا يسمح بصور ذات روابط خارجية أو SVG تنفيذي مستورد.
- `fonts.ts` و`assets/`: 14 عائلة خطوط محلية بأوزان حقيقية ونطاقات Unicode وتراخيصها. SVG يضمّن الخطوط المستخدمة وخط Cairo الاحتياطي للنص العربي؛ بعض برامج المتجهات قد لا تدعم خطوط SVG المضمّنة، فثبّت العائلات محليًا عند التحرير فيها.
- `image-tools.ts`: إزالة الخلفية المتصلة بالحواف وحساب مسارات التحويل البسيط.
- `export-tools.ts`: SVG محمول، تحويله إلى Canvas، التنزيل، وأشكال حزمة العلامة.

## إضافة محتوى أو قسم

1. **رمز:** استورده صراحةً من Lucide في `catalog.ts` وأضفه إلى المجموعة المناسبة؛ المكتبة والمرسم يقرآن السجل نفسه. لإضافة شكل هندسي جديد، أضف اسمه إلى `shapes` وارسمه في `ElementGraphic`.
2. **قالب:** أضف تعريفًا في `templates.ts` أو تركيبًا جديدًا في `templateProject`. أنشئ كل جزء بـ `node()`؛ لا تستخدم صورة مسطحة للقالب.
3. **قسم:** أنشئ ملفًا بجانب الأقسام، استخدم `useDesigner()` للحالة و`t(ar,en)` للنصوص، وسجله في قائمة `tabs` داخل `App.tsx`. لا تحتفظ بنسخة منفصلة من المشروع داخل القسم.
4. **خاصية عنصر:** أضفها إلى `types.ts` والقيمة الافتراضية في `node()`، والتحقق في `storage.ts` إن كانت مطلوبة، ثم المرسم والواجهة واختبارًا. اجعل الخصائص الجديدة اختيارية أو وفّر ترحيلًا لمشاريع الإصدار 1 القديمة.
5. **خط:** ضمّن WOFF2 والترخيص تحت `assets/`، ثم أضفه إلى `fonts.json` مع نطاقات Unicode الصحيحة وأسماء ملفات الوزن؛ لا تعتمد على CDN.

## حدود واضحة وخصوصية

- المساعد **اقتراحات محلية قائمة على قواعد وقوالب**، وليس توليد صور بالذكاء الاصطناعي عبر خدمة خارجية.
- إزالة الخلفية تستهدف لونًا متصلًا بالحواف، وليست قصّ أشخاص أو شعر. المعالجة على نسخة بحد أقصى 1024px؛ التحويل المتجهي يكمّم الألوان ويتتبّع شرائط عند 128px، لذا يناسب الشعارات البسيطة ولا يدّعي تتبّع صور فوتوغرافية احترافيًا.
- النماذج توضيحية CSS/SVG وليست تصويرًا واقعيًا. التصدير يصدّر **الشعار**؛ لا يصدر مشهد النموذج نفسه.
- SVG متجهي بخطوط مضمّنة، PNG يدعم الشفافية، JPG بخلفية بيضاء عند الحاجة. PDF يحتوي صورة عالية الدقة داخل مستند، **وليس PDF بمسارات متجهة**. أبعاد الصور حتى 4096px لكل ضلع، والأبعاد المخصصة قد تمدّ النسبة؛ المقاسات الجاهزة تحافظ عليها.
- ZIP يتضمن SVG وPNG وSVG أحادي اللون وfavicon PNG 64px وصورة حساب 512px ونسخ SVG أفقية ورأسية وJSON. النسخ الأفقية والرأسية تعيد ترتيب مجموعة النص بجوار/أسفل مجموعة الرمز؛ راجع تباعد التصاميم المعقدة قبل النشر.
- المشاريع والصور والألوان محفوظة **في هذا المتصفح فقط**؛ لا مزامنة سحابية. تنزيل JSON هو النسخة الاحتياطية القابلة للنقل. مسح بيانات المتصفح يحذف التخزين المحلي.
- الحذف يطلب التأكيد. الحفظ له حالات انتظار ونجاح وفشل. النوافذ تستخدم `dialog` لنقل التركيز وحبسه واستعادته، وأزرار الأيقونات مسمّاة لقارئات الشاشة.
