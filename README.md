
## Site-wide backup and retired studio pages

`/storage.html` now exports saved site data as one organized ZIP and previews/validates it before a non-destructive restore on another device. See [`site-storage/README.md`](site-storage/README.md) for supported stores, security/privacy exclusions, the 128 MiB safety limit, conflict/partial-failure behavior and verification. Text Studio and PDF Studio pages are retired and redirect home; the independent PDF tools remain available. User data is not deleted by retiring those pages.
