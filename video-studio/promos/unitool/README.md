# Unitool / One Workspace — فيلم تعريفي بالكود

فيلم أفقي **1920×1080، 30fps، 92 ثانية**، مكتوب بـTypeScript/HTML/CSS وSVG. الرسم ليس صور مواقع أو ملفات stock: النوافذ والأيقونات والأوراق والصورة الهندسية والمؤشر والخريطة البصرية كلها دوال في **`film.ts`**. كل مشهد دالة منفصلة؛ المصدر المرئي والصوتي منظمان في ملف واحد.

## الرندر بأمر واحد

من جذر المستودع بعد تثبيت تبعياته (`npm ci`):

```bash
npm run render:unitool
```

المخرجات في `video-studio/promos/unitool/output/`:

- `unitool-1920x1080.mp4` — H.264، `yuv420p`، 30fps ثابت، 2760 فريم، وصوت AAC stereo 48kHz.
- `unitool-film.html` — **ملف HTML مستقل واحد**، يحتوي JavaScript وCSS والخطوط داخل الملف. افتحه مباشرة دون خادم أو إنترنت؛ به تشغيل/إيقاف، seek، التنقل بين المشاهد، وتفعيل معاينة الصوت.
- `previews/00-hook.png` … `previews/07-cta.png` — لقطة PNG لكل مشهد، تُنشأ **قبل** ترميز الفيديو.
- `previews/manifest.json` — أزمنة اللقطات وفحص تحميل الخط وحدود النص.
- `render-report.json` — بيانات الإخراج والتحقق من فك كل فريمات MP4 والصوت.

يستخدم الأمر Playwright/Chromium وFFmpeg. إذا لم يكن Chromium موجودًا، يحاول تثبيته تلقائيًا؛ وإذا لم يوجد FFmpeg، يحاول تثبيت حزمة `imageio-ffmpeg` محليًا داخل `.cache` باستخدام Python 3 + pip. يحتاج ذلك اتصال إنترنت في أول إعداد فقط. تستطيع استخدام binaries محلية بهذه المتغيرات: `STUDIO_CHROMIUM_PATH` و`FFMPEG_PATH`؛ وقد تحتاج `LD_LIBRARY_PATH` إن كان متصفحك المخصص معه مكتبات منفصلة. لا يرفع الأمر ملفاتك لخدمة رندر خارجية.

لقطات فقط للمراجعة قبل بدء الرندر:

```bash
npm run render:unitool -- --preview-only
```

اختبارات المصدر (لا تحتاج متصفحًا):

```bash
npm run test:unitool-promo
```

## التعديل

في أول `film.ts`:

- `CONFIG`: المقاس، FPS، المدة، رابط الموقع، الألوان، مستويات الموسيقى وUI.
- `TIMELINE`: الثواني المطلقة لكل مشهد ووقت لقطة المعاينة. كل الأزمنة داخل دالة المشهد محلية من بدايته. عند تغيير أطوال المشاهد راجع `AUDIO_CUES` ومدد أقسام المشهد والصوت أيضًا؛ لا يدّعي المشروع إعادة توقيت القصة بالكامل آليًا.
- `SCENES`: دوال `sceneHook`، `scenePdf`، `sceneImages`، `sceneDesign`، `sceneAudio`، `sceneIcons`، `sceneMore`، `sceneCta`.
- `AUDIO_CUES`: أصوات click/pop/success، متزامنة مع الأفعال، يمكن تعديل وقت كل صوت.
- `audioSample`: الموسيقى الهادئة والمؤثرات مؤلفة أصلًا بالموجات الجيبية، وليست ملفات موسيقى محمية. لا يوجد تعليق صوتي بشري أو صوت كتاب مسجل.

إيقاف الموسيقى مع إبقاء أصوات الواجهة:

```bash
npm run render:unitool -- --no-music
```

لاستخدام موسيقى تملك حقوقها بدل الموسيقى المولّدة، مع إبقاء UI:

```bash
MUSIC_FILE="/absolute/path/to/music.wav" npm run render:unitool
```

الملف الخارجي يُمزج بمستوى منخفض مع fade دخول/خروج. هذا خيار محلي ولم تُرفق معه موسيقى خارجية. تستخدم إعدادات الصوت الحالية نهاية 92 ثانية؛ إذا عدلت المدة عدّل fades وفقًا لذلك.

خيارات إضافية:

```bash
RENDER_WORKERS=4 UNITOOL_OUTPUT="/path/to/results" npm run render:unitool
```

افتراضيًا هناك عاملان للرسم (من 1 إلى 4). تُجمع لقطات العمال بترتيب رقم الفريم ثم تدخل FFmpeg، مع backpressure وباتش محدود الذاكرة. الرندر ليس تسجيل شاشة بزمن حقيقي؛ البطء لا يسقط فريمات أو يغير المدة. يُكتب فيديو مؤقت ثم يُعتمد الاسم النهائي بعد التحقق، بدل تسليم ملف جزئي كأنه مكتمل.

## العربية والرسوم والتحقق

- Tajawal 700 للعربية واللاتينية، وJetBrains Mono 500 للأوامر والكود. ملفات WOFF2 مضمنة محليًا في HTML؛ تراخيص SIL OFL محفوظة في `assets/`. لا تُحمّل خطوط من Google Fonts أثناء العرض أو الرندر.
- نص SVG له `direction="rtl"` و`unicode-bidi="plaintext"`؛ النص البرمجي LTR. تم فحص اتصال الحروف بصريًا في المشاهد الثمانية. كل سطر رئيسي داخل حدود آمنة؛ يفحص الأمر عينات متتابعة عبر كامل التايم لاين قبل التصدير.
- الانتقالات بسيطة (fade/slide)، والـspring حتمي، والمؤشر يتبع قوسًا مضبوطًا وتظهر موجة عند النقر. لا يوجد `Math.random` في الرسم أو الصوت.
- المصدر يراجع 2760 إطارًا لاكتشاف NaN/Infinity وعدم الحتمية؛ الرندر يفك الملف النهائي كاملًا لعد الفريمات والتحقق من H.264 و1080p و30fps وAAC.

## دقة المحتوى

الواجهات عرض تفسيري، وليست تشغيلًا فعليًا للأدوات أو ضمان سرعة/ضغط لملف بعينه. الصورة في مشهد التحويل رسم متجه أصلي مكتوب بالكود؛ لا يُدّعى أن تحويل أي JPG إلى SVG ينتج tracing متجهيًا حقيقيًا. الأصوات واللغات في قارئ الكتب تعتمد على الأصوات المتاحة بالجهاز. وجدت بالمستودع أدوات PDF والصور والتصميم والقارئ وSVG وQR والضغط؛ بعض أدوات المشهد السابع مثل الحاسبة ومحول الوحدات وJSON ليست صفحات مستقلة موجودة هنا، ولذلك وُسم هذا المشهد بوضوح **تصوّرًا لإضافات**.

عنوان `unitool1.vercel.app` مأخوذ من رابط الأداة الموجود في كود QR بالمستودع (بدون بادئة www)؛ يمكن تغييره في `CONFIG.site`. لم يُختبر اتصال هذا العنوان الحي ضمن الرندر.

المخرجات المولّدة مُستثناة من Git للحفاظ على حجم المستودع. المصدر والخطوط والتراخيص فقط تُحفظ ضمن الكود؛ أعد توليد المخرجات بالأمر أعلاه.

## نتيجة التحقق لهذا التسليم

- تمت مراجعة PNG لكل المشاهد الثمانية **قبل** الرندر النهائي؛ عُدّلت المسافة بين الموجة والوصف ومحاذاة كود SVG بعد المراجعة.
- فُحصت حدود النصوص في عينات خلال كل ثانية من التايم لاين، بالإضافة إلى لقطات المشاهد؛ حُمّل خط Tajawal المضمن وتحقق اتصال العربية بصريًا.
- نجحت 5/5 اختبارات الفيلم، وتفحص توليد جميع 2760 فريمًا للحتمية والهندسة والصوت. نجحت TypeScript للمشروع ولفيلم `film.ts` منفصلًا، و105/105 اختبارات Node للمحرر الموجود. لم تُعد مجموعة متصفح المحرر لهذا التعديل المعزول.
- الرندر النهائي باستخدام 4 عمّال مرتبِين اكتمل، وفُك ملف MP4 كاملًا: **H.264 High / yuv420p / 1920×1080 / SAR 1:1 / 30fps / 2760 frames / 92.00s**، وصوت **AAC LC stereo 48000Hz**. الحجم حوالي **8.5MiB**.
- استُخرجت صور المشاهد الثمانية من H.264 وقورنت بالمعاينات (متوسط فرق قنوات RGB بعد التصغير: حوالي 1.05–1.18 من 255، بسبب الضغط)، ولم تظهر مشاهد مفقودة أو مكررة بدل أخرى.
- فحص الصوت بعد فك AAC: peak حوالي **−18.3dBFS**، بلا NaN/Infinity أو clipping؛ 48 صوت UI فوق موسيقى أصلية هادئة. لا يوجد تعليق صوتي أو تسجيل كلام للكتاب.
- `render-report.json` في مجلد الإخراج يحفظ البيانات الفعلية وسجل FFmpeg والمقارنات. الاختبارات لا تمثل قياسًا على جميع الأجهزة أو المتصفحات.
