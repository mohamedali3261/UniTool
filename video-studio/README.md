# UniTool Video Studio

قسم مستقل مستوحى من سير عمل محررات الفيديو مثل CapCut، بواجهة عربية RTL. التحرير والتصدير محليان؛ مكتبة Pexels اختيارية للبحث عبر الإنترنت وتستخدم إعداد المصمم الموجود بالفعل.

## التشغيل

من جذر المشروع:

```sh
npm ci
npm run dev
```

افتح `/video-studio.html`. الرابط موجود أيضًا في الصفحة الرئيسية وقائمة الموقع.

```sh
npm run lint
npm run test:video-studio
npm run build
```

## الاستخدام والمميزات الفعلية

- استيراد ملفات الفيديو والصور والصوت المدعومة بترميزات المتصفح.
- تركيب عدة مقاطع بالترتيب، إعادة ترتيبها بالسحب (Pointer Events للماوس واللمس) أو بأزرار قبل/بعد، نسخها وحذفها.
- قص البداية والنهاية بالثواني أو بسحب الحواف مباشرة، تقسيم المقطع عند المؤشر، وحذف ما قبل/بعد المؤشر من المقطع الحالي. سرعة من 0.25x إلى 4x.
- سحب المؤشر، جذب مغناطيسي قابل للتعطيل، تكبير بالتحكم أو Ctrl/Cmd + عجلة الماوس، ملاءمة المشروع للعرض، تغيير ارتفاع التايم لاين والتنقل بين حدود المقاطع.
- تحريك توقيت النصوص وسحب حوافها لضبط بداية/نهاية الظهور. النصوص المتداخلة تظهر في صفوف منفصلة، وكل سحبة تسجّل خطوة تراجع واحدة.
- تدوير 90 درجة، عكس أفقي/رأسي، تكبير، احتواء/ملء الكادر، وتلاشي دخول وخروج للصورة وصوت المقطع. التقسيم يحافظ على تلاشي الأطراف الأصلية فقط.
- الصور ثابتة 5 ثوانٍ افتراضيًا ويمكن إطالة عرضها من نهاية القص حتى ساعة.
- نصوص متعددة وملصقات emoji مع اللون والحجم والموضع وتوقيت الظهور.
- ٣٤ فلترًا وتأثيرًا: ١٧ فلتر ألوان وسينما، و١٧ تأثير حركة/إضاءة/ريترو. يمكن تركيب فلتر واحد وتأثير واحد لكل مقطع، مع ضبط الإضاءة والتباين والتشبع.
- صوت مستقل لكل مقطع مع كتم سريع، ومسار موسيقى يمكن تحريك بدايته، قص بدايته من المصدر، تعطيل/تفعيل تكراره والتحكم في مستواه. موجة الصوت تُحسب محليًا من الملف الحقيقي (عند دعم المتصفح لفك الصوت).
- مقاسات 16:9 و9:16 و1:1 و4:5. المعاينة والتصدير يستخدمان دالة الرسم نفسها.
- تنزيل صورة PNG من الإطار الحالي، وملف مشروع JSON يحتوي على الوسائط المضمنة لفتحه لاحقًا.
- تصدير **MP4 أو WebM** بالصوت والنصوص والفلاتر والتحويلات، بدقة ارتفاع 480/720/1080 واختيار 24/30/60 FPS وجودة 2/4/8 Mbps. عدد الإطارات الفعلي أثناء التسجيل يعتمد على قدرة الجهاز، والتحويل إلى MP4 يضبط معدل الملف النهائي.
- MP4 يسجّل مباشرة بترميز المتصفح عندما يدعم H.264/AAC؛ وإلا يسجّل WebM ثم يحوّله في Worker محلي باستخدام `@ffmpeg/core` إلى H.264 + AAC و`yuv420p` و`faststart`، مع تقدم مرحلي وإلغاء.
- ملف JavaScript وWASM لمحرك التحويل يُضمّنان في بناء Vite من الاعتماد npm، ويُحمّلان عند الحاجة من **نفس الموقع**؛ لا توجد روابط CDN. ملفات الوسائط لا تغادر الجهاز. حجم WASM نحو 32 MB غير مضغوط، ولا يوضع يدويًا في Git.
- أسماء تنزيل الملفات تتحول لاسم لاتيني آمن لضمان بقاء الامتداد؛ اسم المشروع العربي محفوظ داخل المشروع.
- تراجع وإعادة، تنبيه قبل إغلاق الصفحة أثناء وجود مشروع، وتصميم للموبايل.

## الحدود المقصودة

- التصدير محلي وبالوقت الحقيقي، وليس رندرًا أسرع من مدة الفيديو. احتفظ بالصفحة ظاهرة؛ الأداء وعدد الإطارات يعتمدان على الجهاز والمتصفح. Chrome/Edge الحديثان هما الخيار المفضل.
- تحويل MP4 الاحتياطي يستهلك ذاكرة ووقتًا إضافيين بعد التسجيل؛ للفيديوهات الطويلة استخدم دقة أقل أو WebM. أول تحويل يحتاج تحميل المحرك من الموقع. لا يوجد وعد بـAI UHD أو 4K.
- دقة التصدير هي **ارتفاع** الفيديو؛ مع المقاس العمودي 9:16 ودقة 720 يكون العرض قرابة 406 بكسل. افتراضيًا المحتوى يظل كاملًا مع أشرطة (contain)، ويمكن اختيار ملء الكادر (cover) أو تكبيره لكل مقطع.
- المسار الأساسي متتالٍ، وفوقه حتى ٦ طبقات صور/فيديو ثم النصوص. يوجد مسار موسيقى واحد، وانتقالات عند القطع، وKeyframes للمقاطع الأساسية. يمكن تحريك المقطع والطبقات والنصوص مباشرة في المعاينة، مع ضبط توقيت الطبقات بالسحب أو بالأرقام. لا يوجد محرر منحنيات Bezier.
- لا يتضمن التعرف التلقائي على الكلام أو إزالة الخلفية بالذكاء الاصطناعي؛ هذه الميزات تحتاج محركًا أو خدمة منفصلة ولم تُعرض كأزرار وهمية.
- الحفظ التلقائي يستخدم IndexedDB على نفس المتصفح والجهاز، ولا يرفع الملفات. قد تمنع إعدادات الخصوصية التخزين أو يمسحه المتصفح؛ **احتفظ بنسخة JSON خارجية للمشاريع المهمة**. الإغلاق أثناء مهلة الحفظ أو قبل اكتماله قد يفقد آخر التعديلات.
- ترميزات HEVC وبعض ملفات MOV تختلف حسب المتصفح؛ عند تعذّر القراءة يظهر خطأ، واستخدام MP4/H.264 أو WebM أكثر توافقًا.

## التحقق

اختبارات Node تغطي حساب المدة والسرعة والقص، حدود المؤشر، ملفات المشروع المضمنة، ورفض الروابط الخارجية والملفات غير الصالحة. تم أيضًا اختبار مسار الاستيراد، النصوص، التراجع والإعادة، تصدير فيديو WebM وإعادة فتح مشروع، وعرض الموبايل 390px باستخدام Chromium في بيئة التطوير.


## ترخيص محرك MP4

الاعتماد `@ffmpeg/core` موزّع تحت **GPL-2.0-or-later** ويشمل ترميز x264؛ راجع متطلبات التوزيع والترخيص عند نشر حزمة المحرك مع الموقع. المصادر وإرشادات البناء: https://github.com/ffmpegwasm/ffmpeg.wasm وhttps://github.com/ffmpegwasm/ffmpeg.wasm/tree/main/packages/core . لا يُغيّر هذا الملف تلقائيًا ترخيص بقية المشروع.

## اختبارات التحديث

اختبارات العمليات تغطي الجذب وإعادة الترتيب وحدود القص وصفوف النصوص وتوقيت الموسيقى والتلاشي والتحقق من حقول المشروع الجديدة مع استمرار دعم ملفات version 1 القديمة. فُحصت تفاعلات السحب بالمتصفح، والتراجع بخطوة واحدة بعد السحب، وتحويل MP4 الاحتياطي الحقيقي وفك ترميز إطاراته (وليس فحص اسم الامتداد فقط)، وعرض الموبايل 390px.


## مكتبة المؤثرات والأداء والموبايل

- **Motion for React** (الاعتماد `motion` الموجود أصلًا) هو مكتبة حركات الواجهة، عبر `LazyMotion` و`m` و`MotionConfig`، لا مكتبة ثانية كبيرة أو CDN.
- مؤثرات الفيديو نفسها تعتمد على **Canvas 2D** ودوال زمنية حتمية. الدالة المشتركة `drawFrame` تُستخدم في المعاينة وكروت العرض والتصدير، لذلك المؤثرات لا تختفي في MP4/WebM. مؤثر الفيلم الحبيبي يرسم عددًا محدودًا من النقاط، لا يمرّ على كل بكسل. هذه مؤثرات إبداعية خفيفة، وليست LUT ثلاثي الأبعاد أو محاكاة فيلم فيزيائية.
- الكروت تعرض مشهدًا توضيحيًا محليًا مع حركة مصدر بسيطة، وليست نسخة مصغرة من ملف المستخدم. الصورة تُقرأ مرة واحدة، والكروت لا ترسم حتى تقترب من الشاشة. كارت واحد يتحرك تلقائيًا ويمكن إيقافه أو تشغيل غيره. التبديل أو خروج الكارت من الشاشة أو إخفاء الصفحة يوقف الحلقة. تشغيل الفيديو والتصدير يوقفان حركة الكروت مؤقتًا.
- البحث، الأقسام والمفضلة حقيقية؛ المفضلة وتفضيلات الأداء وسجل بحث Pexels (حتى ٥ كلمات) تُحفظ في `localStorage`، مع تحمّل تعذّر التخزين. ملفات المشاريع ليست محفوظة تلقائيًا.
- لكل مقطع فلتر وتأثير واحد (إمكان تركيب الاثنين معًا)، وشدة 0–100% وسرعة 0.25–2x للمؤثرات الزمنية. المؤثرات الثابتة لا تعرض منزلق سرعة غير مؤثر. يمكن حذف الفلتر والتأثير كلٌ على حدة. ملفات version 1 القديمة تستمر في العمل.
- المعاينة المتوقفة **لا تحتوي حلقة رسم مستمرة**؛ تعاد عند تغيير المشروع أو الوقت أو تحميل/سعي الوسيط. أثناء التشغيل تُحدّث الساعة بحد أقصى 30 مرة/ثانية، مع عزل مكتبة الوسائط والخصائص عن تحديثات التشغيل عبر `memo` ومعالجات ثابتة.
- جودة المعاينة: تلقائي 640 بكسل للهواتف والأجهزة اللمسية الصغيرة و960 للديسكتوب، خفيف 480، وعالي 1280 (عرض اللوحة). وضع خفيف يوقف معاينات الكروت ويقترح تصدير 480p. جودة التصدير مستقلة. الأجهزة التي تبلغ عن ذاكرة ≤2 GB لا تشغّل معاينات حيّة تلقائيًا في وضع تلقائي.
- `prefers-reduced-motion` مراقب عند التحميل **وعند تغيّره**: يوقف حركة الكروت ويخفّف حركة الواجهة، لكنه لا يغيّر التأثير المختار في ملف الفيديو.
- الموبايل له شريط أدوات سفلي ثابت مع safe-area، ترويسة لمس، أقسام أفقية قابلة للتمرير، خصائص قابلة للطي، وزر عودة للمعاينة. شريط الأدوات وكروت المعاينة لها أهداف لمس ≥44px. حقول الإدخال 16px لتفادي التكبير التلقائي في Safari، مع معالجة الوضع الأفقي والأجهزة اللمسية حتى 900px.
- التصدير يجهّز أول إطار قبل التسجيل ويضيف ساعة صوت صامتة لمنع قصر التسجيلات المكوّنة من صور على أجهزة بطيئة. وجود مسار صامت في فيديو بلا موسيقى مقصود، ولا يضيف صوتًا مسموعًا.

### إضافة تأثير جديد

أضف تعريفًا إلى ملف `effects.ts` في القسم المناسب، بمعرّف فريد ووصف عربي و`kind`. الفلتر يحتاج `css`، والحركة تحتاج `camera(frame)`، والطبقة الرسومية تحتاج `overlay(ctx,frame)`؛ يمكن الجمع بين الكاميرا والطبقة. لا تستخدم `Math.random` أو الوقت الحقيقي أو الشبكة داخل الرسم؛ استخدم `frame.t` و`frame.progress` لكي يتطابق التصدير مع المعاينة. الأقسام مسجلة في `registry.ts`، والتحقق من ملفات المشروع يتحدث تلقائيًا من الفهرس. نفّذ `npm run test:video-studio` بعد التعديل.

### تحقق هذا التحديث

في تحديث المؤثرات السابق، كانت هناك ٢٣ اختبار Node تغطي أيضًا المعرّفات القديمة والجديدة، الحتمية وحدود الكاميرا وشدة صفر وسرعة الحركة وحفظ إعدادات المؤثرات. اختبارات Chromium بتفاعل لمس/أحجام 320 و360 و390 و768 والوضع الأفقي 844×390 تحققت من عرض البداية والمحرر دون تمدد أفقي، وأزرار شريط الأدوات، والمفضلة والبحث ووضع خفيف وتقليل الحركة، وعدم الرسم المستمر للمعاينة المتوقفة. جُرّب تصدير MP4 بتأثير إضاءة وفك ترميز إطاره للتحقق من ظهور التأثير، لا الامتداد فقط.

هذه اختبارات أحجام ولمس **بالمحاكاة** وليست شهادة أداء لكل هاتف؛ لم يُقَس معدل الإطارات على iPhone/Android حقيقيين في هذه البيئة. الفيديوهات الطويلة/1080p/60FPS ومحرك MP4 يمكن أن يستهلكوا ذاكرة ووقتًا، لذلك لا يوجد ضمان بعدم التعليق على كل جهاز. جرّب وضع خفيف و480p أو WebM للأجهزة المحدودة، واختبر Safari/iOS على جهاز فعلي قبل إطلاق واسع.


## تحديث مكتبة Pexels والقوائم

### الاستخدام

من **وسائط ← مكتبة Pexels** اختر الصور أو الفيديوهات، واكتب كلمة بحث واضغط Enter أو زر البحث. توجد اقتراحات عربية، وآخر ٥ عمليات بحث مع زر مسح السجل. ترجمة الكلمات العربية المعروفة تتم محليًا باستخدام نفس قاموس المصمم، ولا تُرسل الكلمات لخدمة ترجمة أخرى. الكلمات غير المعروفة تُرسل كما هي؛ جرّب الإنجليزية عند الحاجة.

- عرض مختارات عند فتح المكتبة، مع فلتر أفقي/رأسي/مربع. تطبيق المقاس دون كلمة بحث يستخدم نتائج «background» بدل مختارات لا تدعم فلتر الاتجاه.
- ١٢ نتيجة لكل دفعة، بحد ٦ دفعات (٧٢ كارتًا) للبحث الواحد لتقييد الذاكرة. يمكن تضييق البحث للحصول على نتائج أخرى. بيانات النتائج في cache مؤقت بالذاكرة لخمس دقائق، بحد ٢٤ صفحة.
- المعاينة في نافذة أصلية `dialog` تدعم Escape وحجز التركيز وإعادته. لا يُشغّل كل كارت فيديو تلقائيًا؛ الفيديو يُحمّل عند فتح معاينته فقط. الصور مصغّرة وكسولة التحميل. كروت النتائج `memo` ولا تعاد مع كل تحديث لتقدم التنزيل.
- HD يستهدف ضلعًا أطول حتى ١٢٨٠ بكسل وFull HD حتى ١٩٢٠. للفيديو يُختار أفضل MP4 متاح ضمن الحد، وإلا أصغر ملف متاح. المقاس الفعلي ظاهر في المعاينة؛ الجودة ليست ترقية لدقة المصدر ولا ضمانًا بأن Pexels يوفّر كل المقاسات.
- زر + ينزّل الملف عبر CORS إلى `File` محلي ثم يمرره لنفس `readAsset` المستخدم لملفات الجهاز. لا تدخل روابط CDN في الخط الزمني أو لوحة Canvas، للحفاظ على تصدير غير ملوّث وحفظ مشروع مستقل عن الإنترنت.
- التنزيل واحد في المرة، قابل للإلغاء، بحد أقصى ١٠٠ MiB، مع فحص حجم الاستجابة **وأثناء قراءة التدفق** وفحص MIME، ومهلة خمول ٣٠ ثانية. الإلغاء أو مغادرة المكتبة يوقف التنزيل/قراءة metadata وينظف المصدر المؤقت، دون إضافة مقطع ناقص. تقدم التنزيل محدود بـ١٠ تحديثات/ثانية تقريبًا.
- اللقطة الموجودة في ملفاتك بنفس الجودة تُستخدم مجددًا دون تنزيل أو إنشاء Asset مكرر؛ إضافة نسخ للخط الزمني تظل ممكنة. التراجع يزيل المقطع مع إبقاء الملف في مكتبتك.
- اسم صاحب العمل ورابط صفحة Pexels والجودة محفوظة في `Asset.source`، وتظهر في الخصائص والملفات المحلية وتبقى في JSON. التحقق من version 1 يقبل المصدر الاختياري الموثوق، ويظل يرفض روابط الوسائط الخارجية. بيانات المصدر القديمة غير الموجودة تظل مدعومة.
- البحث يُلغى عند تغييره أو مغادرة التبويب، وتُرفض الاستجابات المتأخرة. أخطاء الاتصال/الصلاحيات/حد الطلبات تظهر بوضوح مع إعادة محاولة؛ لا تُعامل كبحث فارغ. تراخيص Pexels والإسناد متاحة في المكتبة والمعاينة، وحقوق الأشخاص والعلامات والاستخدامات المقيدة مسؤولية المستخدم.

  useStockSearch.ts       # حالة البحث والإلغاء ومنع السباق

  StockPreview.tsx        # dialog للمعاينة والإسناد

`stock/api.ts` يعيد استخدام `PEXELS_API_KEY` من خدمة المصمم، دون تكرار المفتاح أو طلب إدخاله. **هذا إعداد client-side موجود في المشروع**: المفتاح قابل للقراءة في حزمة المتصفح، وليس سرًا محفوظًا على الخادم. للنشر العام مع حماية الحصة، انقل المصادقة إلى proxy خادم مع rate limiting وغيّر المفتاح المنشور؛ لا تعتبر `VITE_*` مكانًا لإخفاء الأسرار. لم يُضف خادم تجريبي يعمل فقط محليًا أو proxy خارجي غير موثوق. لا يُرسل المفتاح إلى CDN أو التخزين المحلي، ولا تُرفع ملفات المستخدم إلى Pexels.

كل قوائم المقاس والسرعة والملاءمة والأداء والتصدير تستخدم `StudioSelect`، مع مؤشّر اختيار ووصف اختياري وtypeahead وتنقل بالأسهم وEscape، وحركة تركيز صحيحة، وقوائم لا تُقص داخل لوحة الخصائص. مقاس الأزرار ≥٤٤ بكسل، وشريط التمرير native ملوّن دون JavaScript أو حلقات إعادة رسم. تفعيل زر بالمسافة لا يشغّل خط الفيديو عرضًا.

إعداد المتصفح في `playwright.video-studio.config.ts`. يمكن تحديد `STUDIO_QA_URL` لاختبار نسخة إنتاج تعمل بالفعل و`STUDIO_CHROMIUM_PATH` لمسار متصفح بديل. ملف `tests/fixtures/stock-video.mp4` فيديو H.264 صامت بلون ثابت، ٢ ثانية، مولّد للاختبار، وليس مادة من Pexels. نتائج الاختبارات ولقطات الفشل مستبعدة من Git؛ تسجيل traces معطّل لتفادي تسجيل بيانات المصادقة.

اختبارات المتصفح تغطي الصور **وMP4 حقيقيًا**، المعاينة، pagination، البحث الفارغ، 429 وإعادة المحاولة، السباق بين طلبين، استخدام الملف المحلي مجددًا، قوائم الأداء والتصدير، Space/Escape، الحفظ وإعادة الفتح بعد منع طلبات Pexels، الإلغاء وFull HD، وعدم التمدد الأفقي وتصادم القوائم على لمس 320×740 و390×844 و768×1024 و844×390.

**طلبات API وCDN في هذه الاختبارات mocked**؛ بيئة التطوير لا تستطيع الوصول مباشرةً إلى Pexels، ولذلك لم يُتحقق من صلاحية المفتاح أو حصة الحساب أو النتائج الحية هنا. يلزم اختبار مباشر من متصفح المستخدم المتصل بالإنترنت، وكذلك اختبار Safari/iOS على جهاز فعلي قبل إطلاق واسع.


## الحزمة الإبداعية: الانتقالات والتحريك والقوالب والاسترجاع والطبقات

### أماكن الأدوات

- **الخصائص ← انتقال إلى المقطع**: اختر المقطع الثاني أو أي مقطع لاحق، ثم تلاشي متبادل/سحب/زووم/وميض ضوئي، واضبط ٠٫١–٣ ثوانٍ واضغط «معاينة الانتقال». أول مقطع لا يحتاج انتقالًا قبله. تظهر علامة ◇ على المقاطع التي لها انتقال.
- **الخصائص ← تحريك الصورة وKeyframes**: اقتراب/ابتعاد/تحريك أفقي هادئ؛ تعمل أيضًا على الفيديو. أضف حتى ٢٠ Keyframe للمكان الأفقي والرأسي والحجم والشفافية عند المؤشر، ثم حرّر القيم أو احذف النقطة أو اعرضها. الوقت محلي للمقطع بعد تطبيق السرعة، والاستيفاء خطّي. التقسيم يحافظ على استمرارية منحنى النقاط ويعيد توقيت النصف الثاني؛ نقاط خارج حدود المقطع بعد قصّه لا تُعرض؛ لا يوجد محرر منحنيات أو مسارات تحريك مباشرة على Canvas.
- **النصوص ← التوقيت والحركة وإعدادات إضافية ← تحريك النص**: دخول وخروج منفصلان، بتلاشي أو حركة من أسفل أو Pop؛ تأثير الآلة الكاتبة للدخول، مع مدة قابلة للضبط. تُقسّم الكتابة إلى graphemes عند توافر `Intl.Segmenter` لتجنب قطع الحروف المركبة والإيموجي.
- **بداية الاستوديو ← القوالب**: ريلز، إعلان منتج، اقتباس، وعرض صور. القوالب مكتملة بمقاسات ونصوص وحركات وانتقالات؛ خلفياتها SVG تصميمية مولّدة محليًا وليست صورًا فوتوغرافية أو مواد جاهزة من خدمة خارجية. عدّل النصوص، واستبدل المصادر من **الخصائص ← استبدال مصدر المقطع** بملفاتك أو لقطات Pexels التي أضفتها للمكتبة. بدء قالب ينشئ مشروعًا جديدًا بعد طلب تأكيد ومحاولة حفظ السابق.
- **الخصائص ← طبقات إضافية**: حتى ٦ طبقات صور/فيديو، مستقلة عن المسار الأساسي. اختر ملفًا موجودًا أو «رفع ملف كطبقة فقط» دون إضافته للمسار الأساسي، ثم اضبط توقيت الظهور، القص من المصدر، مدة العرض، X/Y، الحجم، الشفافية، التدوير والصوت. الصوت مكتوم افتراضيًا للطبقات. زرّا ↑/↓ يغيّران ترتيب الرسم؛ آخر طبقة فوق الباقي، والنصوص فوق الجميع. تظهر صفوف منفصلة للطبقات في التايم لاين، والنقر عليها ينقل المؤشر ويفتح خصائصها. يمكن تحريك الطبقات وقص حوافها مباشرة في الخط الزمني، أو ضبطها رقميًا من الخصائص.

### دقة التوقيت والرسم

`composition/scene.ts` هو مخطط المشهد، و`lib/media.ts` يركّب المشهد نفسه للمعاينة والصورة الثابتة وتصدير MP4/WebM. الانتقالات تتم **حول نقطة القطع** دون تقصير المشروع أو تحريك الموسيقى والنصوص: النصف الأول في نهاية المقطع السابق والثاني في بداية التالي، ويثبت إطار المصدر عند الحافة خارج نطاقه. المدة الفعلية لا تتجاوز طول أي من المقطعين ولا ٣ ثوانٍ. هذا اختيار توقيت صريح، وليس overlap/ripple يغيّر طول التايم لاين.

لكل استخدام من الفيديو decoder مستقل بمفتاح المقطع/الطبقة، حتى عند استخدام نفس الملف مرتين بوقتين مختلفين. `PreviewMedia` يحتفظ بوسائط المشهد النشط فقط ويحرّر مصادر الفيديو والمستمعين والمهل عند المغادرة. المعاينة المتوقفة لا تحتوي حلقة رسم؛ يبدأ التحديث فقط مع الوقت أو المشروع أو الوسائط. التصدير يجهّز مصادره مسبقًا، ويستخدم Canvas capture بتوقيت fps مع سطح رسم صغير شبه شفاف لتجنب اختفاء الالتقاط تحت compositing. التصدير ما زال بالوقت الحقيقي؛ عدد الإطارات الفعلي وحركة الفيديو يعتمدان على قدرة الجهاز والمتصفح، خصوصًا مع عدة فيديوهات و1080p.

### الحفظ التلقائي ومساحة التخزين

- `persistence/database.ts`: قاعدة IndexedDB باسم `unitool-video-studio`، بمتجرين للمشاريع وملفات Blob. تُحفظ الوسائط المستخدمة في المسار الأساسي **والطبقات** والموسيقى، لا روابط blob المؤقتة ولا Base64 ضخم مكرر عند الاسترجاع.
- عزل ملفات كل مشروع بمفتاح مركّب يمنع ملفًا يحمل نفس Asset ID في مشروع آخر من الكتابة فوقه. حفظ بيانات المشروع ووسائطه يتم في معاملة ذرية؛ تُحذف الوسائط غير المشار إليها مع الإبقاء على ملفات المشاريع الأخرى. لا يُعاد جلب Blob لم يتغير أثناء كل تعديل للنص.
- `useAutosave.ts`: حفظ بعد هدوء التعديلات ١٫٥ ثانية، بطابور تسلسلي حتى لا تكتب نسخة قديمة فوق الأحدث، ومحاولة حفظ عند إخفاء الصفحة وقبل فتح مشروع/قالب آخر. حذف كل المقاطع يُحفظ أيضًا، فلا يسترجع المشروع المقاطع المحذوفة بالخطأ. تظهر حالة الحفظ في الترويسة/التذييل.
- **مشاريعك على الجهاز** تعرض المشاريع بترتيب آخر تعديل، مع استرجاع وحذف مؤكد. استرجاع البيانات يمر بنفس التحقق من الملفات المحمولة، ويُصفّر سجل Undo عند الانتقال لمشروع آخر. حذف سجل محلي لا يحذف نسخة JSON نزلتها سابقًا.
- `navigator.storage.estimate()` يعرض تقدير استخدام وحصة الموقع إن دعمه المتصفح، وتنبيهًا عند تجاوز ٨٠٪. طلب `persist()` يحتاج موافقة وسياسة المتصفح ولا يضمن الحماية؛ عند الرفض يظهر تنبيه. خطأ امتلاء المساحة أو منع IndexedDB لا يعطل التحرير أو تنزيل JSON.
- الحفظ ليس مزامنة سحابية ولا نسخة احتياطية مضمونة. البيانات خاصة بالأصل/المتصفح/الجهاز، وقد يمسحها المستخدم أو وضع التصفح الخاص أو المتصفح نفسه. لا يوجد ضمان لحفظ آخر ١٫٥ ثانية أو لإنهاء معاملة أثناء انهيار المتصفح/إغلاقه بالقوة.

### الاختبارات الحالية

٦٨ اختبار Node تشمل الحسابات السابقة، توقيت الانتقالات والحواف، حركة Keyframes والنصوص، التحقق من الحقول الجديدة، وعزل ملفات المشاريع والاسترجاع الذري وتنظيف التخزين باستخدام `fake-indexeddb` (اعتماد تطوير فقط). ٢٨ اختبار Playwright تشمل الاختبارات السابقة بالإضافة إلى تعديل القوالب والنقاط واسترجاعها بعد reload، امتلاء مساحة التخزين مع استمرار تنزيل JSON، الرفع كطبقة فقط، حفظ حذف كل المقاطع، واستخدام نفس الفيديو في المسار الأساسي وطبقة بتوقيت مختلف. التحقق من التصدير يفك ترميز **MP4 وWebM** ويبحث في إطاراتهما عن دمج لونَي المقطعين والطبقة الخضراء، لا فحص الامتداد وحده. اختبار الالتقاط يستخدم 480p ومشهدًا أطول لتجنب الاعتماد على FPS أو توقيت تقديم إطار واحد داخل بيئة headless.

اختبارات اللمس على 320×740 و390×844 و768×1024 و844×390 تتحقق من القوالب والطبقات والقوائم دون تمدد أفقي. هذه محاكاة Chromium، وليست قياسًا لهاتف فعلي أو ضمانًا لأداء عدة فيديوهات على iOS. اختبارات Pexels ما زالت mocked كما هو موضح أعلاه.


## تعديل مباشر داخل المعاينة + نصوص أبسط

- اختار العنصر بالنقر على صورته/نصه، أو من قائمة **عناصر المعاينة** لتصل للطبقات المتداخلة والمخفية والمقفولة. اسحب لتحريكه مع أدلة جذب لمركز الكادر. المقابض تغيّر الحجم مع الحفاظ على النسبة وتدوّر العنصر بحرية؛ Shift مع التدوير يثبت الزاوية كل ١٥ درجة.
- شريط المعاينة يتيح التكبير والتصغير، تدوير ٩٠ درجة، التوسيط الأفقي والرأسي، النسخ، القفل، إخفاء النص/الطبقة، إعادة ضبط التحويل وحذف العنصر. طبقة النسخة السابعة لا تُضاف؛ حد الطبقات ما زال ٦.
- ضغطتان على النص أو زر **النص** يفتح الكتابة داخل المعاينة. **تم** أو Ctrl+Enter يؤكد التعديل، و**إلغاء** أو Esc يتراجع عن المسودة. لا تدخل المسودات في ملف المشروع أو الحفظ التلقائي قبل تأكيدها.
- الأسهم أثناء التركيز على مساحة التعديل تحرّك العنصر بمقدار بكسل عرض واحد؛ Shift يحركه ١٠ بكسل. Delete/Backspace يحذف المحدد فقط، Ctrl+D ينسخه، وEsc يلغي السحبة. كل سحبة مكتملة تسجّل **خطوة تراجع واحدة**، وليس خطوة لكل حركة للمؤشر. تغير حجم النافذة أو فقد اللمس يلغي السحبة غير المكتملة.
- وضع **مشاهدة** يعطّل التقاط اللمس فوق الكادر لتمرير الصفحة على الموبايل. التعديل المباشر يتوقف أثناء تشغيل الفيديو. المقابض خارج الكادر تُقص؛ استخدم أزرار الشريط للعنصر الذي يملأ الكادر أو يمتد خارجه.
- قسم النصوص يعرض قائمة مختصرة ومحررًا **لنص واحد فقط**: كتابة، ألوان سريعة، حجم، عريض، حدود، خلفية وثلاث عائلات خطوط نظامية. التوقيت والشفافية وحركة الدخول والخروج داخل إعدادات مطوية. الخطوط الفعلية تعتمد على الخطوط المثبتة في جهاز المستخدم.
- `preview/model.ts` يحتوي تحديد العنصر وهندسة القياس واختبار النقر والتحويلات غير المتلفة؛ `preview/Interaction.tsx` يعالج المؤشر واللمس والكيبورد ومسودات السحب. `text/layout.ts` يشارك الخط والقياسات مع الرسم والتصدير، و`text/TextPanel.tsx` يفصل واجهة النصوص المبسطة عن المكتبة.
- التحريك الثابت يُضاف فوق الحركة وKeyframes الموجودة، ولا يسجّل نقاط حركة تلقائيًا. المؤثرات الزخرفية خارج حدود الصورة لا تدخل في نطاق تحديدها. أدوات التحديد DOM منفصلة، فلا تظهر في الصور أو MP4/WebM.
- ٨ اختبارات Node إضافية لهندسة المقاس والدوران والحدود والتحقق من الملفات، و٥ اختبارات Chromium إضافية للسحب والإلغاء والتراجع بخطوة، المقابض والتدوير الحر، تعديل النص داخل المعاينة، النسخ والقفل والإخفاء، وتفاعل لمس حقيقي بمحاكاة 390px. لا تُعدّ المحاكاة قياس أداء على أجهزة موبايل فعلية.


## Timeline Pro — أدوات الخط الزمني الموسّعة

- **الطبقات:** اسحب وسط طبقة الصورة/الفيديو لتغيير توقيتها، أو حافتيها لقص المصدر/مدة الظهور. جميع السحبات لها مسودة محلية، خطوة Undo واحدة عند الإفلات، وEsc أو إلغاء اللمس يلغي المسودة.
- **التحديد الجماعي:** Shift/Ctrl مع النقر، أو زر «تحديد متعدد» على الموبايل، ثم اختر المقاطع والنصوص والطبقات. النصوص والطبقات تتحرك مع الحفاظ على فواصلها؛ المقاطع الأساسية يعاد ترتيبها ككتلة في مسار متتالٍ، وليست مقاطع حرة فوق بعضها.
- **الربط:** زر السلسلة يجمع التحديد، وفك السلسلة يفك المجموعة. العناصر المرتبطة تتبع توقيت المقطع عند إعادة ترتيبه. نسخ مجموعة ينشئ Group IDs جديدة حتى لا تتحرك النسخ مع المجموعة الأصلية. حد طبقات الصور/الفيديو يظل ٦.
- **Ripple:** مفعّل افتراضيًا. حذف المقاطع أو قصها يقفل المسافة ويحرّك التوقيت اللاحق للنصوص والطبقات والعلامات وبداية الموسيقى، مع احترام المسارات المقفولة. عند تعطيله، حذف/تقصير المقطع يحتفظ بفاصل مظلم بنفس المدة؛ زر «حذف الفراغات» يغلق الفواصل. تمديد حافة مقطع مع Ripple معطّل لا يكتب فوق المقطع التالي؛ فعّل Ripple للتمديد.
- **صور مصغّرة وموجات فعلية:** حتى ٥ إطارات لكل مقطع فيديو، تُقرأ عند اقتراب المقطع من مساحة العرض، بطابور فك ترميز واحد وذاكرة مخبأة محدودة. صورة الموجة مبنية على تحليل الصوت الحقيقي للموسيقى والفيديو، وليست رسمة عشوائية. التحليل يبدأ قرب الصفوف المرئية وبطابور واحد؛ ملفات أكبر من 64MiB أو أطول من 10 دقائق تستمر في التشغيل لكن بدون تحليل كامل للموجة لحماية الذاكرة. ملف بلا صوت أو ترميز غير مدعوم لا يحصل على موجة وهمية.
- **Markers:** زر العلم يضيف علامة عند المؤشر، ويمكن تسميتها وتلوينها وسحبها أو الانتقال إليها وحذفها. الحد ٥٠٠ علامة؛ تُحفظ داخل JSON وIndexedDB.
- **Keyframes:** النقاط تظهر أسفل المقاطع؛ اسحبها لتعديل الوقت، أو أضف عند المؤشر/بضغطتين على شريط النقاط. يمكن حذف النقطة واختيار خطية، Ease In، Ease Out أو Ease In/Out للوصول إليها. هذه الانسيابية تعمل في المعاينة والتصدير، والتقسيم يحتفظ بأجزاء منحنى الانسيابية نفسه باستخدام نافذة منحنى داخلية، لا مجرد تقريب قيم الأطراف. لا يوجد محرر مقابض Bezier.
- **أدوات المسارات:** قائمة ⋯ بجوار اسم المسار تتيح الاسم والقفل والإخفاء/الكتم والطي والارتفاع. إخفاء المسار يؤثر في المعاينة والتصدير وليس واجهة التايم لاين فقط. المقاطع المقفولة تمنع إعادة ترتيب يغيّر توقيتها، وقفل المسار يمنع تعديل عناصره من التايم لاين والمعاينة.
- **قائمة سريعة:** كليك يمين أو ضغطة مطولة: تقسيم عند مؤشر داخل المقطع، نسخ/حذف التحديد، ربط/فك ارتباط، سرعة 0.5×/1×/2×، فصل الصوت وتجميد إطار.
- **فصل الصوت:** غير متلف؛ يشغّل صوت ملف الفيديو نفسه على مسار الموسيقى المستقل، بنفس القص والسرعة، ويكتم النسخة الأصلية. يوجد **مسار موسيقى واحد**؛ استبدال موسيقى موجودة يتطلب تأكيدًا. ليس هذا إنشاء ملف صوت منفصل على القرص. تغيير المصدر بعد ذلك يصفر حدود وسرعة الصوت المنفصل.
- **تجميد إطار:** يلتقط مصدر المقطع عند المؤشر، ويطبّق قصه وألوانه وحركته وتأثيره، ثم يدخل صورة ثابتة لمدة ثانيتين مع تقسيم المقطع عند الحاجة. النصوص والطبقات لا تُحرق في الصورة لتجنب تكرارها. الصورة بحد أقصى ضلع 1920px وتبقى قابلة للنقل داخل ملف المشروع.
- **اللمس والقص الدقيق:** تكبير بإصبعين حول نقطة اللمس، وCtrl+Wheel حول المؤشر، وتمرير مستمر عند حافة الشاشة أثناء السحب. «اعرض المشروع كله» و«تكبير عند المؤشر» متاحان، و«قص دقيق» يعرض شبكة فريمات 30 FPS ويضبط السحب على الفريم. شبكة التحرير هنا 30 FPS، وليست كشفًا تلقائيًا لمعدل المصدر أو تغييرًا لإعداد FPS في التصدير.
- **الجذب:** حدود المقاطع والنصوص والطبقات والعلامات وبداية الصوت والمؤشر، مع دليل مرئي. يمكن تعطيله من زر المغناطيس.

الكود موزع بين `pages/Editor/Timeline.tsx` لتنسيق التفاعلات و`pages/Editor/timeline/` لعمليات التحرير غير المتلفة، قارئ الإطارات والصور المصغرة، أدوات المسارات والقائمة السريعة. الإعدادات الجديدة اختيارية وتظل ملفات version 1 القديمة صالحة. metadata المسارات التي تُحذف طبقاتها تنظّف مركزيًا قبل الحفظ.

أضيفت ١٣ حالة Node لهندسة عمليات المجموعة، الفراغات وRipple، حماية المسارات، نسخ المجموعات، قص المصدر، فصل الصوت وتوقيت السرعة، استمرار الانسيابية بعد التقسيم والتحقق من metadata. وأضيفت ٧ حالات Playwright للسحب والقص والإلغاء والتراجع، الربط والنسخ، الفراغات، العلامات والنقاط والقفل، الصور المصغّرة والموجة الحقيقية، فصل الصوت والتجميد، تكبير بإصبعين والقائمة بالضغط المطوّل والتمرير عند الحواف. اللمس مختبر بمحاكاة Chromium، وليس قياس أداء على هاتف فعلي.
