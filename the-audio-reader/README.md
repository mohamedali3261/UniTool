# القارئ الصوتي

المدخل `/the-audio-reader.html`، وكل مكونات القارئ في هذا المجلد.

## القراءة العربية

- تنظيف Unicode محافظ: لا تبديل تخميني للكلمات ولا حذف شامل للتشكيل.
- المقاطع تُقسم عند الكلمات واللغة إلى نحو 220 حرفًا؛ حتى وضع الصفحة يشغّل مقاطع قصيرة متتابعة لتقليل مشكلة اقتطاع المتصفحات للنص الطويل.
- اختيار صوت يطابق لغة المقطع؛ غياب صوت عربي يظهر إرشادات التثبيت، وليس بديلًا إنجليزيًا صامتًا.
- أخطاء النطق توقف المقطع وتتيح إعادة تشغيله؛ لا نتخطّى المقطع الذي فشل.
- جلسات النطق تعزل أحداث الإلغاء القديمة، وتنسيق ملكية محرك المتصفح يمنع تنظيف معاينة أو ترجمة قديمة من إيقاف القراءة الجديدة.
- خريطة إزاحات للنص المنطوق تحفظ مطابقة تمييز الكلمات بعد تسوية Unicode. بعض الأصوات لا ترسل أحداث تمييز كلمات؛ القراءة نفسها لا تعتمد عليها.
- الصفحات الفارغة لا تُحذف من الكتاب أو يتغير ترقيمها؛ يمكن استخراج نص الصور عبر OCR. جودة استخراج PDF/OCR تظل معتمدة على الملف.

**الحدود:** نختبر عدم إسقاط الكلمات التي تُرسل لمحرك الصوت وتسلسل المقاطع، وليس دقة النطق المسموع لكل صوت. تثبيت صوت عربي مناسب مطلوب، والجودة والعمل دون إنترنت يعتمدان على النظام/المتصفح والصوت المختار. إيقاف مؤقت أنهى المتصفح نطقه قد يعيد آخر كلمة بدل تخطّي بقية النص. توجد خدمات ترجمة وأصوات وخلفيات خارجية قد تحتاج الإنترنت.

## النوافذ والقوائم

`DialogBackdrop` يوحّد الإغلاق بالنقر خارج النافذة أو Escape وحبس/استعادة التركيز وقفل تمرير الخلفية. إخفاء نافذة OCR لا يلغي المهمة؛ الإلغاء بزرها المخصص. `DismissiblePopover` يغلق قوائم السرعة والصوت والخلفية والمؤقت والتصدير عند النقر خارجها أو Escape.

## التحقق

```sh
npm run lint
npm run test:audio-reader
npm run test:audio-reader:browser
npm run build
```

اختبارات المتصفح تستخدم محرك صوت مزيّفًا لتسجيل النصوص والأحداث بدون أصوات النظام. يمكن تحديد `STUDIO_CHROMIUM_PATH` أو `READER_QA_URL` لاختبار خادم إنتاج قائم.
