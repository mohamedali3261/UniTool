# UniTool PDF Studio

مساحة مستقلة لقراءة PDF والتعليق وتنظيم الصفحات، متاحة عبر `/pdf-studio/`. عربية/إنجليزية، RTL/LTR، تعمل محليًا في المتصفح. لا تعتمد على المحرر القديم أو تخزينه، ولا تعيد استخدام إضافات بين ملفات مختلفة.

## القراءة العربية: حدود صريحة

- PDF.js يرسم الصفحة الأصلية، مع CMaps وخطوط قياسية محلية؛ لا نعيد تركيب النص الأصلي كعناصر HTML مرئية، ولا نطلب خطًا عربيًا من CDN أثناء التصدير.
- نستخرج Unicode من طبقة النص؛ نجمع مقاطع السطر حسب مواضعها، ونوصل مقاطع الكلمات المتقاربة دون إدخال مسافات داخلها. **لا نقلب حروف الكلمات العربية**. يظل ترتيب الملف الخام متاحًا للمقارنة. تستخدم هندسة القراءة إحداثيات غير مدوّرة، بينما تظليل البحث يستخدم إحداثيات الصفحة المرئية.
- التشكيل والتطويل وبعض أشكال الألف/الياء يتم تجاهلها في **البحث فقط** دون تغيير النص المستخرج. البحث يعمل عبر مقاطع كلمة واحدة، وفي كل الصفحات الأصلية عند الطلب.
- الترتيب الهندسي تقريب، وليس فهمًا مضمونًا للجداول أو الأعمدة أو النص المائل. لا توجد خوارزمية موثوقة لإصلاح Unicode مفقود من الخط. نعرض تحذيرًا عند ترميز تالف أو صفحة بلا نص، وندعو لمقارنة الأصل أو OCR. استخراج الصفحة محدود بـ10 آلاف مقطع/200 ألف حرف مع تحذير عند القطع.
- OCR بـTesseract عربي+إنجليزي محلي، مع تخطيط تلقائي أو فقرة أو نص متناثر، وتقدم وإلغاء ومهلة دقيقتين. الصور تُرسم عند حد طويل 2600 بكسل، مع مراعاة تدوير المستخدم. لا توجد طلبات خدمات OCR خارجية، وملفات اللغات والمحرك تُخدم من نفس الموقع.
- **لا يمكن ضمان دقة 100%**. OCR قد يخطئ بالأسماء والأرقام والتشكيل، بل قد يسقط سطرًا كاملًا. في عينة Amiri المصوّرة للاختبار قرأ المحرك «الفاتورة»، «القاهرة» والأرقام، لكنه أسقط السطر الأول. الاختبارات لا تدّعي قراءة كل السطور. نعرض «ثقة المحرك» لا «نسبة دقة»، مع نص قابل للتصحيح وعلامة مراجعة يدوية.
- النصوص المكتشفة قابلة للنسخ والتنزيل TXT. نتائج OCR وتصحيحاتها مؤقتة للجلسة؛ **ليست طبقة نص مضمنة في PDF**، ولا تدخل مشروع JSON. احفظ TXT قبل مغادرة الجلسة.

## الحروف العربية وترميز الخطوط

- تُحوَّل أشكال العرض العربية مثل `ﻧﻮع` إلى حروف Unicode عادية مثل `نوع` في العرض والنسخ وTXT، دون تطبيع شامل قد يغيّر الأرقام أو المعرّفات.
- رموز الخط الخاصة (PUA) لا تحمل معنى موحدًا؛ نعرض `�` بدل تخمين حرف مفقود، مع تنبيه بعدد الرموز وأكوادها وخيار تشغيل OCR المحلي. مثلًا `ﻧﻮع اﻟﺄﺳﻴﺲ` يصبح `نوع ال�أسيس`، وليس كلمة مكتملة مُختلقة. راجع الأسماء والأرقام والتواريخ يدويًا.
- يمكن اختيار النص الخام للتشخيص؛ النسخ وTXT يتبعان نمط العرض المختار. تبقى بيانات الاستخراج الأصلية وإحداثياتها محفوظة داخليًا.
- اختبار خط اصطناعي يغطي الرموز الخاصة والتطبيع والتصدير والنص الخام ومدخل OCR؛ لا يثبت استعادة مستند مستخدم دون اختبار ملفه الأصلي، ولا يضمن ترتيب الأعمدة في كل PDF.

## التحرير والتصدير

- إضافة نص عربي/إنجليزي بخط Amiri، تظليل، رسم حر، إطار، وغطاء أبيض، تحديد وتحريك الطبقات، تعديل الخصائص والموضع والمقاس. إحداثيات بالنقاط، مستقلة عن التكبير، وتعمل مع تدوير الصفحة وحدود CropBox غير الصفرية.
- ترتيب/نسخ/تدوير/حذف الصفحات، 40 خطوة تراجع/إعادة. لا يمكن حذف آخر صفحة.
- الأصلي محفوظ دون تعديل. التصدير ينسخ الصفحات الأصلية دون تحويلها كلها إلى صور، ثم يضيف تعليقاتك كصورة شفافة عالية الدقة. الرسم نفسه مستخدم في المعاينة والتصدير لضمان تشكيل العربي متطابقًا. **النص المضاف ليس قابلًا للبحث** لأنه مُدمج كصورة؛ النص الأصلي القابل للاستخراج يبقى قابلًا للاستخراج.
- الأدوات الأساسية محرر إضافات فوق الصفحات، وليست إعادة تدفق للفقرات. يوجد مسار منفصل محدود لتعديل النص الأصلي كما هو موضح أدناه. الغطاء الأبيض ليس حجبًا آمنًا: المعلومات تحته لا تُحذف. لا تستخدمه لإخفاء بيانات حساسة.
- يحفظ مشروع JSON التعليقات وترتيب الصفحات فقط، ويرتبط بـSHA-256 لملف PDF الأصلي. الاستيراد يرفض ملفًا آخر، حتى لو له نفس الاسم. مفيش حفظ تلقائي للملفات أو التعليقات في localStorage؛ اللغة فقط محفوظة. احفظ PDF/JSON يدويًا قبل الإغلاق. يُنبه المتصفح عند وجود تعديلات غير مصدّرة.
- PDF.js لا يشغل JavaScript/روابط PDF أو XFA في هذه الواجهة. التصدير ليس مسارًا للحفاظ على التوقيعات الرقمية والمرفقات والنماذج التفاعلية والبيانات الوصفية؛ قد تضيع أو تصبح غير صالحة. ملفات كلمة المرور تتطلب نسخة مفتوحة ومصرّحًا بها.
- الحدود: 25 MB للـPDF، 100 صفحة، أبعاد 5000 نقطة كحد أقصى لكل بعد، 500 إضافة للمستند/100 للصفحة، ألف حرف للنص المضاف، 1500 نقطة للمسار، 5 MB لمشروع JSON. ميزانية رسم 12 مليون بكسل لكل canvas.

## تعديل النص الأصلي — مرحلة أولى محافظة

- زر «تعديل النص الأصلي (محدود)» يُجهّز نسخة تشمل ترتيب الصفحات والإضافات الحالية، ثم يفحص الصفحة المختارة. لا يحوّل الصفحة الأصلية لصورة ولا يستبدل النص بغطاء أبيض.
- الدعم مقصود أن يكون ضيقًا: كتل مستقلة `q BT … ET Q` بأوامر ألوان وخط ومصفوفة ونص hex واحدة معروفة؛ أي stream يحتوي أوامر أخرى يُرفض بالكامل. لا ندّعي دعم جميع ملفات PDF.
- يمكن تحريك الكتل المدعومة بإزاحة أفقية/رأسية بالنقاط أو حذفها فعليًا من المحتوى. تعديل الحروف مقتصر على ASCII قابل للطباعة بخطوط Type1 القياسية غير المضمنة وترميز WinAnsi دون ToUnicode مخصص. تغيير حروف النص العربي داخل خط مضمّن وتحرير الصور الأصلية غير مدعومين في هذه المرحلة. السحب المباشر متاح للكتل النصية المدعومة، ومنها الكتل العربية المستقلة التي يمكن عزلها دون تخمين. لا يتم تخمين الأحرف المفقودة.
- الحركة بنظام إحداثيات PDF الأصلي قبل تدوير الصفحة: الموجب يمين/أعلى. قد يتداخل النص الجديد مع عناصر أخرى أو يتجاوز الحدود، ولذلك يلزم مراجعة النسخة. الحذف ليس حجبًا آمنًا للمعلومات من المستند كاملًا.
- إنشاء النسخة لا يغيّر الجلسة الحالية. يمكن تنزيلها أو فتحها للمراجعة؛ فتحها يبدأ جلسة جديدة بعد تأكيد المستخدم، ولا يحتفظ بسجل التراجع السابق. كل عملية تنشئ نسخة جديدة ويمكن تكرارها بعد فتح النسخة. الأصلي لا يتغير.
- الاختبارات تغطي تغيير أوامر النص الحقيقية، بقاء الأصل، التحريك المتكرر والحذف، رفض البنية/الترميز غير المدعومين، وعدم تغيير صفحة أخرى تشترك في نفس content stream، وفتح النسخة في المتصفح للتحقق من النص المستخرج.

## التحريك المباشر على الصفحة بالماوس واللمس

- داخل «تعديل النص الأصلي (محدود)» توجد معاينة الصفحة الأصلية: اضغط إطار كتلة لتحديدها ثم اسحبها. على الهاتف افتح «الأدوات» أولًا. الكتلة المحددة هي الوحيدة التي تُطبّق عليها العملية؛ أنشئ النسخة وافتحها قبل تعديل كتلة أخرى. التحديد المرئي محدود لأول 100 كتلة مدعومة.
- لا تُنقل طبقة لقطة فوق النص القديم: تُرسم خلفية معاينة بلا الكتلة المحددة، والكتلة نفسها بطبقة شفافة أثناء السحب. الحفظ يغيّر content stream فعليًا ويحتفظ بالحروف والخط؛ المعاينة ليست طريقة التصدير.
- إطار التحديد يستخرج من PDF.js لنسخة معزولة من الكتلة **بنفس موارد الخط وحدود الصفحة وتدويرها**، وليس بالتخمين من نص مشابه أو أقرب إحداثيات. يُرفض الدعم بعد أوامر سابقة غير معروفة قد تغيّر مصفوفة الإحداثيات أو القص عبر streams.
- تحويل المؤشر عبر مصفوفة SVG العكسية ثم viewport PDF.js يحسب الإزاحة مع التكبير والتدوير وحدود CropBox. القيم محفوظة حتى 0.001 نقطة، وهذا دقة تخزين الإحداثيات لا ضمان دقة اللمسة أو كل ملفات PDF. المعاينة تكبر حتى 3×، والأسهم تتحرك نقطة واحدة وShift+سهم 0.1 نقطة باتجاه الشاشة.
- pointer capture يحتفظ بالسحب عند خروج المؤشر من الإطار. pointercancel/fقد الالتقاط يلغي الحركة غير المكتملة. لكل سحبة خطوة تراجع واحدة، مع إعادة وتصفير الموضع. التمرير من خارج إطارات النص يظل متاحًا على الهاتف.
- للنص القابل للاستبدال فقط: زر «تعديل النص على الصفحة» أو النقر المزدوج يفتح حقلًا في الصفحة. تغيير الحروف يُرى في النسخة بعد إنشائها وفتحها؛ السحب يعاين الحروف الأصلية. النص العربي غير القابل للاستبدال يظل قابلًا للتحريك عند دعم بنية كتلته دون إعادة تشكيله.
- اختبارات المتصفح تتحقق من السحب مع تدوير 0/90/180/270، وحدود صفحة مزاحة وتكبير، والتراجع والإعادة والتحريك الدقيق بالأسهم، وأحداث لمس حقيقية عبر Chromium CDP وإلغاء اللمس، والتحريك العربي مع حفظ النص، والتعديل داخل الصفحة وفتح النسخة الناتجة.
- العينة `tests/fixtures/arabic-native-movable.pdf` اصطناعية، من خط Amiri الموجود في `assets/amiri-arabic-400-normal.woff2` برخصة OFL المرفقة في `assets/amiri-LICENSE.txt`. حُوّل الخط إلى TTF وقُلّص بواسطة FontTools/Brotli لإنشاء عينة pdf-lib بخط عربي مضمّن. أُنشئت ToUnicode وعروض CIDs للحروف المشكّلة من ناتج fontkit للنص الأصلي المعروف، لتجاوز نقص خرائط glyphs البديلة في مولّد العينة؛ لا تحتوي بيانات مستخدم.

## البناء والاختبار

```sh
npm ci
npm run dev                # predev يجهز الأصول المحلية تلقائيًا
npm run lint
npm run test:pdf-studio
npm run test:pdf-studio:browser
npm run build              # prebuild يجهز الأصول ثم يبني جميع المداخل
```

اختبارات المتصفح تقبل `PDF_QA_URL` لنسخة إنتاج، و`STUDIO_CHROMIUM_PATH` لمتصفح مخصص. تتضمن: PDF عربي بنص وأرقام وتشكيل، OCR حقيقي دون شبكة خارجية، إلغاء OCR، حدود الهاتف 320/390/768، تراجع/إعادة، استعادة مشروع ببصمة صحيحة ورفض أخرى، تصدير وإعادة قراءة، وفحص بكسلات الإضافات على تدويرات 0/90/180/270 وحدود CropBox مزاحة.

`make-fixtures.mjs` يحتاج dev server ومتصفحًا لإنشاء PDFs اصطناعية من خطوط المشروع؛ لا يحتوي الاختبار مستندات مستخدمين.
