# UniTool PDF Studio

مساحة مستقلة لقراءة PDF والتعليق وتنظيم الصفحات، متاحة عبر `/pdf-studio/`. عربية/إنجليزية، RTL/LTR، تعمل محليًا في المتصفح. لا تعتمد على المحرر القديم أو تخزينه، ولا تعيد استخدام إضافات بين ملفات مختلفة.

## القراءة العربية: حدود صريحة

- PDF.js يرسم الصفحة الأصلية، مع CMaps وخطوط قياسية محلية؛ لا نعيد تركيب النص الأصلي كعناصر HTML مرئية، ولا نطلب خطًا عربيًا من CDN أثناء التصدير.
- نستخرج Unicode من طبقة النص؛ نجمع مقاطع السطر حسب مواضعها، ونوصل مقاطع الكلمات المتقاربة دون إدخال مسافات داخلها. **لا نقلب حروف الكلمات العربية**. يظل ترتيب الملف الخام متاحًا للمقارنة. تستخدم هندسة القراءة إحداثيات غير مدوّرة، بينما تظليل البحث يستخدم إحداثيات الصفحة المرئية.
- التشكيل والتطويل وبعض أشكال الألف/الياء يتم تجاهلها في **البحث فقط** دون تغيير النص المستخرج. البحث يعمل عبر مقاطع كلمة واحدة، وفي كل الصفحات الأصلية عند الطلب.
- الترتيب الهندسي تقريب، وليس فهمًا مضمونًا للجداول أو الأعمدة أو النص المائل. لا توجد خوارزمية موثوقة لإصلاح Unicode مفقود من الخط. نعرض تحذيرًا عند ترميز تالف أو صفحة بلا نص، وندعو لمقارنة الأصل أو OCR. استخراج الصفحة محدود بـ10 آلاف مقطع/200 ألف حرف مع تحذير عند القطع.
- OCR بـTesseract عربي+إنجليزي محلي، مع تخطيط تلقائي أو فقرة أو نص متناثر، وتقدم وإلغاء ومهلة دقيقتين. الصور تُرسم عند حد طويل 2600 بكسل، مع مراعاة تدوير المستخدم. لا توجد طلبات خدمات OCR خارجية، وملفات اللغات والمحرك تُخدم من نفس الموقع.
- **لا يمكن ضمان دقة 100%**. OCR قد يخطئ بالأسماء والأرقام والتشكيل، بل قد يسقط سطرًا كاملًا. في عينة Amiri المصوّرة للاختبار قرأ المحرك «الفاتورة»، «القاهرة» والأرقام، لكنه أسقط السطر الأول. الاختبارات لا تدّعي قراءة كل السطور. نعرض «ثقة المحرك» لا «نسبة دقة»، مع نص قابل للتصحيح وعلامة مراجعة يدوية.
- النصوص المكتشفة قابلة للنسخ والتنزيل TXT. نتائج OCR وتصحيحاتها مؤقتة للجلسة؛ **ليست طبقة نص مضمنة في PDF**، ولا تدخل مشروع JSON. احفظ TXT قبل مغادرة الجلسة.

## التحرير والتصدير

- إضافة نص عربي/إنجليزي بخط Amiri، تظليل، رسم حر، إطار، وغطاء أبيض، تحديد وتحريك الطبقات، تعديل الخصائص والموضع والمقاس. إحداثيات بالنقاط، مستقلة عن التكبير، وتعمل مع تدوير الصفحة وحدود CropBox غير الصفرية.
- ترتيب/نسخ/تدوير/حذف الصفحات، 40 خطوة تراجع/إعادة. لا يمكن حذف آخر صفحة.
- الأصلي محفوظ دون تعديل. التصدير ينسخ الصفحات الأصلية دون تحويلها كلها إلى صور، ثم يضيف تعليقاتك كصورة شفافة عالية الدقة. الرسم نفسه مستخدم في المعاينة والتصدير لضمان تشكيل العربي متطابقًا. **النص المضاف ليس قابلًا للبحث** لأنه مُدمج كصورة؛ النص الأصلي القابل للاستخراج يبقى قابلًا للاستخراج.
- هذا محرر إضافات فوق الصفحات، **وليس إعادة تحرير للنص الأصلي داخل بنية PDF أو إعادة تدفق فقراته**. الغطاء الأبيض ليس حجبًا آمنًا: المعلومات تحته لا تُحذف. لا تستخدمه لإخفاء بيانات حساسة.
- يحفظ مشروع JSON التعليقات وترتيب الصفحات فقط، ويرتبط بـSHA-256 لملف PDF الأصلي. الاستيراد يرفض ملفًا آخر، حتى لو له نفس الاسم. مفيش حفظ تلقائي للملفات أو التعليقات في localStorage؛ اللغة فقط محفوظة. احفظ PDF/JSON يدويًا قبل الإغلاق. يُنبه المتصفح عند وجود تعديلات غير مصدّرة.
- PDF.js لا يشغل JavaScript/روابط PDF أو XFA في هذه الواجهة. التصدير ليس مسارًا للحفاظ على التوقيعات الرقمية والمرفقات والنماذج التفاعلية والبيانات الوصفية؛ قد تضيع أو تصبح غير صالحة. ملفات كلمة المرور تتطلب نسخة مفتوحة ومصرّحًا بها.
- الحدود: 25 MB للـPDF، 100 صفحة، أبعاد 5000 نقطة كحد أقصى لكل بعد، 500 إضافة للمستند/100 للصفحة، ألف حرف للنص المضاف، 1500 نقطة للمسار، 5 MB لمشروع JSON. ميزانية رسم 12 مليون بكسل لكل canvas.

## البناء والاختبار

```sh
npm ci
npm run dev                # predev يجهز الأصول المحلية تلقائيًا
npm run lint
npm run test:pdf-studio
npm run test:pdf-studio:browser
npm run build              # prebuild يجهز الأصول ثم يبني جميع المداخل
```

اختبارات المتصفح تقبل `PDF_QA_URL` لنسخة إنتاج، و`STUDIO_CHROMIUM_PATH` لمتصفح مخصص. تتضمن: PDF عربي بنص وأرقام وتشكيل، OCR حقيقي دون شبكة خارجية، إلغاء OCR، حدود الهاتف 320/390/768، تراجع/إعادة، استعادة مشروع ببصمة صحيحة ورفض أخرى، تصدير وإعادة قراءة، وفحص بكسلات الإضافات على تدويرات 0/90/180/270 وحدود CropBox مزاحة.

`make-fixtures.mjs` يحتاج dev server ومتصفحًا لإنشاء PDFs اصطناعية من خطوط المشروع؛ لا يحتوي الاختبار مستندات مستخدمين.
