# UniTool Sheet Studio — استوديو الجداول

أداة مستقلة في `/excel-studio/`، لا تعتمد على كود محرر الفيديو أو الشعارات أو القارئ الصوتي. الروابط فقط مشتركة مع دليل UniTool. ملفات الأصول والخطوط محلية داخل هذا المجلد.

## المتاح

- جداول متعددة، كتابة قيم أو صيغ، مراجع بين الأوراق، أرقام عربية/إنجليزية، تنسيقات عملة/نسبة/تاريخ، ألوان ومظاهر، صف عنوان وتثبيت رؤوس وتظليل متبادل.
- مساعد للجمع والمتوسط والشروط والبحث والنسب والضرب والتقريب. ليس نموذج AI ولا يدّعي فهم طلبات حرة.
- 421 دالة ومرجع، لكل منها وصف ومثال؛ 388 مثالًا قابلًا للتنفيذ داخل المحرر، والباقي موسوم **مرجع Excel**. الدوال الشائعة مشروحة بالعربية، والتوثيق التفصيلي للمتقدمة ومعاملاتها بالإنجليزية من مصادر MIT. رقم «مثال يعمل» ليس ضمان توافق كل مدخلات الدالة مع Excel.
- القوالب: مبيعات وميزانية وفاتورة ومخزون ودرجات ورواتب وحملات ومشروعات وسفر واشتراكات وصفحة فارغة. كلها خلايا وصيغ قابلة للتعديل وليست صورًا.
- Shift+نقرة لتحديد نطاق، تنسيق جماعي، لصق TSV من Excel، تعبئة معادلات نسبية لأسفل، ترتيب بالعمود المحدد مع تثبيت العنوان وصفوف الإجمالي المسماة Total/الإجمالي.
- التصفية بصرية فقط؛ الحساب والتصدير يشملان كل الصفوف. الطباعة تشمل الصفوف المعروضة.
- رسوم أعمدة/خطوط قابلة للتنزيل كـSVG. السالب مميز بالأحمر مع ارتفاع بالقيمة المطلقة، وليس محورًا سالبًا منفصلًا.
- حفظ تلقائي محلي للمشروع الحالي، و40 خطوة تراجع/إعادة. تنزيل ملف المشروع هو النسخة الاحتياطية الدائمة؛ مسح بيانات المتصفح يمسح الحفظ المحلي.

## توافق الملفات والحدود

- XLSX: استيراد قيم وصيغ وتنسيق أساسي، وتصدير كل الأوراق مع الصيغ والنتائج المخزّنة وتنسيقاتها. Excel يعيد الحساب عند الفتح.
- CSV/TSV: الاستيراد لا ينفّذ الصيغ تلقائيًا؛ يحفظ ما يبدأ بـ`=` كنص. CSV المصدّر يحوي القيم فقط ويحيّد النصوص القابلة لحقن معادلات.
- مشروع UniTool JSON: يحفظ نموذج الأداة بما فيه كل إعدادات الأوراق والخلايا.
- 8 أوراق، 300 صف × 30 عمودًا لكل ورقة، 20 ألف خلية مخزنة إجمالًا، ملف 5 MB، و25 MB محتوى XLSX مفكوك. هذه أداة للعمل الخفيف وليست بديل Excel الكامل.
- الدمج والماكرو والجداول المحورية المتقدمة وقواعد تنسيق Excel الشرطي والكائنات والرسوم المضمنة والمراجع لملفات خارجية ليست مدعومة، ولا نستوردها بصمت على أنها مدعومة. الاستيراد يعرض تنبيهًا قبل استبدال الملف.
- المصفوفات المتدفقة غير مدعومة؛ تظهر `#ARRAY!` بدل تجاهلها. بعض الدوال قد تعمل كمدخل لدالة أخرى بدون نتيجة متدفقة. `EXPAND` و`MUNIT` محجوبتان قبل التخصيص، وتكرار النص محدود؛ `XIRR` مرجع فقط لأن تنفيذه upstream يستخدم حلقة غير محدودة.
- لا توجد مكالمات شبكة للحساب أو ملفات المستخدم. المحرر يستخدم `fast-formula-parser` و`@formulajs/formulajs`، دون `eval`، مع فحص المراجع الدائرية وحدود حجم الصيغ والتبعيات. لا توجد مطابقة مضمونة لكل تفاصيل دوال Excel المالية/الإحصائية والتواريخ القديمة.
- دوال الوقت والعشوائية تتغير عند إعادة إنشاء الحساب (تعديل البيانات). أمثلة المكتبة تعليمية وليست نصيحة مالية.

## الاختبار والبناء

```sh
npm run lint
npm run test:excel-studio
npm run test:excel-studio:browser
npm run build
npm run catalog:excel-studio
```

لا يحتاج تجديد الكتالوج اتصالًا خارجيًا: يقرأ التوثيق من إصدار Formula.js المقفل ويعيد استخدام الأمثلة الموجودة. مصادر الأمثلة الأولية: اختبارات MIT في `LesterLyu/fast-formula-parser`. تراخيص التوثيق والخطوط في `assets/`. لتوجيه اختبارات المتصفح لنسخة إنتاج اضبط `EXCEL_QA_URL`، ولـChromium مخصص اضبط `STUDIO_CHROMIUM_PATH`.

## Analytics — لوحة تحليلات مرتبطة بالشيت

صفحة مستقلة في `src/pages/analytics/`، مقسمة إلى `AnalyticsPage`, `WidgetCard`, `WidgetEditor`, `VisualChart`, `FilterPanel` وملف CSS. الحسابات والأنواع مستقلة في `core/analytics.ts` و`analyticsTypes.ts`؛ لا توجد واجهة Power BI خارجية أو بيانات وهمية في التقارير.

- اختيار ورقة مصدر، قراءة النتائج المحسوبة للصيغ، مؤشرات KPI وأهداف، أعمدة وخطوط ومساحة ودائري وانتشار وملخص تجميعي مبسط؛ مجموع/متوسط/عدّ غير الفارغ/عدّ مميز/أدنى/أقصى.
- فلاتر مركبة، نقر فئة لتصفية التقرير، تجميع تاريخ شهري/سنوي، عرض بيانات وجدول بديل للرسوم. الدائري يستبعد الصفر والسالب، بينما محور الأعمدة والخطوط يدعم السالب.
- تصميم وإضافة ونسخ وحذف وترتيب العناصر بالسحب أو الأزرار، عرض كامل، حتى 20 عنصرًا و8 فلاتر. الفئات المعروضة محدودة إلى 50 بحد أقصى؛ المقاييس تستخدم كل السجلات المصفاة.
- تنزيل CSV للبيانات المصفاة، PNG للوحة، SVG لكل رسم، والطباعة/PDF عبر المتصفح. إعدادات التقرير محفوظة في مشروع JSON والحفظ المحلي وتدعم التراجع؛ لا تُضمّن في XLSX أو CSV.
- المصدر ورقة واحدة لكل تقرير. لا تتضمن DAX/Power Query/علاقات جداول/اتصالات قواعد بيانات/سحابة أو صلاحيات مشاركة Microsoft Power BI. عند حذف الورقة تظهر دعوة لإعادة ربطها. تغيير المصدر يعيد بناء العناصر؛ يمكن التراجع.
- استبعاد الإجماليات اختيار مبني على اسم أول خلية؛ أخطاء الصيغ لا تدخل المقاييس الرقمية. عدّ KPI الافتراضي يعد القيم غير الفارغة في عمود الفئة، وليس بالضرورة كل الصفوف إذا كان هذا العمود ناقصًا.

### تحسينات المحرر والقوالب الجديدة

`TableTools.tsx` و`core/tableFeatures.ts`: التفاف النص، إظهار الصيغ، تغيير عرض العمود بالسحب أو الأسهم عند تركيز حافته، بحث واستبدال بمعاينة دون لمس الصيغ، قواعد إدخال رقمية/قائمة/تاريخ، وتنسيق شرطي (أكبر/أصغر/بين/تكرار/فراغ/احتواء). القواعد تطبق على الإدخالات واللصق الجديدة باستثناء العناوين، وتسمح بالصيغ دون التحقق من ناتجها، ولا تعدل البيانات القديمة. التنسيق الشرطي والإعدادات محفوظة في JSON فقط، ولا تستورد/تصدّر كقواعد Excel.

خمسة قوالب إضافية في `data/extraTemplates.ts`: رواتب، عائد حملات، تقدم مشروعات، مصروفات سفر، واشتراكات متكررة. كلها بالعربية والإنجليزية مع بيانات نموذجية وصيغ حقيقية. أسعار تحويل السفر بيانات تعليمية ثابتة وليست أسعارًا حية؛ نسب الضرائب/الخصومات ليست استشارة مالية.

## شروحات المعادلات بالحركة

قسم «بيانات المثال» يدعم أول دفعة من **10 دوال شائعة** (اختيار تعليمي، وليس ترتيب استخدام إحصائي): SUM، AVERAGE، COUNT، COUNTA، MAX، MIN، IF، SUMIF، COUNTIF، VLOOKUP. تبويب «شرح بالحركة · 10» يعرض هذه الدروس فقط. البحث باسم مطابق تمامًا يقدّمه على المطابقات الجزئية.

لكل دالة ملف مستقل داخل `src/pages/functions/animations/` باسمها (`SUM.ts`…`VLOOKUP.ts`). الملف يحدد الصيغة، الهدف، خطوات عربية/إنجليزية، مراجع الخلايا المقروءة/المستخدمة/المتجاهلة، الحساب المرحلي، الناتج، وتنبيهًا تعليميًا. `FormulaAnimation.tsx` مشغّل مشترك فقط، وليس ملفًا يجمع محتوى الدروس العشرة؛ `types.ts` للأنواع والبيانات المشتركة، و`index.ts` للتسجيل.

التشغيل يبدأ بطلب المستخدم، مع إيقاف/استكمال، سابق/تالٍ، إعادة، سرعة، وقفز لأي خطوة. تغيير الخطوة يدويًا يوقف التشغيل. مؤقتات التشغيل تنظف عند الإغلاق وتتوقف عند إخفاء الصفحة. تقليل الحركة يعطّل الانتقالات مع إبقاء الخطوات والشرح متاحين؛ الحالات موضحة بنصوص ورموز، وليس اللون وحده.

هذه رسوم تعليمية لصيغة ثابتة على نفس بيانات المثال، وليست تتبعًا داخليًا لمحرك Excel. تعديل تجربة المعادلة لا يغيّر الدرس أو ملف المستخدم. زر «ضع مثال الشرح في التجربة» ينقل الصيغة إلى التجربة فقط؛ الإضافة للملف تظل بالزر الصريح الموجود. COUNT يستخدم A1:C3 ليوضح الفرق بين 6 خلايا رقمية و9 خلايا غير فارغة في COUNTA؛ صيغته ظاهرة بوضوح وقد تختلف عن المثال المختصر في بطاقة المكتبة. الدوال الأخرى تحتفظ بعرض البيانات المعتاد.

الاختبارات تقارن نتائج الدروس بمحرك الحساب الفعلي، وتفحص المراجع واللغتين والتحكم الزمني والاستقلال عن التجربة والموبايل وتقليل الحركة. التشغيل: `npm run test:excel-studio` و`npm run test:excel-studio:browser`؛ إعدادات المتصفح تقبل `EXCEL_QA_URL` و`STUDIO_CHROMIUM_PATH`.

### تحديث الشرح بالمؤشر والكتابة داخل الخلية

العرض الرئيسي الآن جدول تعليمي صغير A1:D3، وليس بطاقات الحساب الملونة: المؤشر يختار D1، يكتب أجزاء الصيغة حرفًا حرفًا داخلها وفي شريط الصيغة، يسحب نطاقًا مرئيًا، ثم يحاكي Enter ويعرض الناتج في D1. IF يختار مرجعًا واحدًا؛ SUMIF يسحب نطاق الشرط ثم نطاق الجمع؛ VLOOKUP يسحب جدول البحث. كل ملف دالة مستقل يحتوي على تسلسل `demo` الخاص به، بالإضافة إلى شرح الحساب الأصلي داخل «ليه الناتج ده؟».

`demoModel.ts` يحسب نص الصيغة المرحلي وموقع المؤشر ومستطيل التحديد دون تغيير ملف المستخدم أو محرك الحساب. المشغّل يحفظ موضع الكتابة والسحب أثناء الإيقاف، وينظف المؤقتات عند الإغلاق، ويتوقف في الخلفية. التنقل اليدوي يعرض نهاية الخطوة المختارة؛ الإعادة ترجع إلى الخلية الفارغة. تقليل الحركة يعرض الحالة المكتملة لكل خطوة دون تحريك المؤشر أو الكتابة المتدرجة. هذه محاكاة تعليمية للإدخال، وليست أتمتة للماوس الحقيقي أو تعديلًا لملف المستخدم؛ التطبيق الحقيقي يظل عبر التجربة وزر الإدراج الصريح.
