# Product Studio / استوديو المنتجات

صفحة مستقلة على `/product-studio/`. واجهة عربية/إنجليزية، RTL/LTR، فاتح/داكن، تعمل محليًا بدون سيرفر لمعالجة الصور.

## تنظيم الملفات

- `index.html`, `main.tsx`, `App.tsx`: الدخول وربط الحالة والأقسام.
- `sections/TopBar.tsx`: اسم المشروع، التراجع والإعادة، حفظ وفتح ملفات المشاريع.
- `sections/ProductPanel.tsx`: اختيار القطعة ولون الخامة.
- `sections/DesignPanel.tsx`: إضافة نص/صورة/شكل وإدارة الطبقات وترتيبها وقفلها وإخفاؤها.
- `sections/Inspector.tsx`: خصائص النص واللون والموقع والحجم والدوران والشفافية والتوسيط.
- `sections/StageDesk.tsx`: مساحة العمل، اختيار الوجه/الظهر و2D/3D وأدوات الكاميرا والدليل.
- `sections/Editor2D.tsx`: سحب وتغيير حجم الطبقات، مع نفس الرسم المستخدم للتصدير.
- `sections/Preview3D.tsx`: مشهد Three.js بإضاءة وظلال ومجسم قابل للدوران، وتصدير الكاميرا.
- `sections/PresetsPanel.tsx`: بدايات تصميم جاهزة.
- `sections/ExportPanel.tsx`: خيارات PNG والدقة والخلفية؛ نافذة تدعم لوحة المفاتيح.
- `sections/StatusBar.tsx`: حالة الحفظ وبدء مشروع جديد.
- `core/model.ts`: نموذج المشروع وإدارة الطبقات والتحقق من الملفات المستوردة.
- `core/history.ts`: تراجع/إعادة محدود بـ40 خطوة، يجمع إيماءة السحب في خطوة واحدة.
- `core/artwork.ts`: الرسم الحقيقي على Canvas، تحميل الصور محليًا وتطبيعها.
- `core/garment.ts`: مجسمات أصلية حجمية بجذع دائري، أكمام منحنية مجوفة، كابيشون مفتوح وجيب وأساور وخياطة.
- `core/fabric.ts`: الثنيات ونسيج القماش ومواد الخامة وسطح مشترك للجذع والتصميم.
- `sections/FabricPanel.tsx`: وضعية الأكمام والثنيات والنسيج والخشونة وقوة الإضاءة وزاويتها.
- `sections/PatternDesk.tsx`: خريطة 2D مستقلة أسفل المجسم للأمام والخلف والأكمام وجانبي الكابيشون، مع سحب الرسم وتراجع مشترك.
- `tests/`: اختبارات منطقية واختبارات متصفح فعلية.

## الاستخدام

1. اختر تيشيرت أو هودي أو سويت شيرت أو حقيبة قماش ولونها.
2. أضف نصًا أو PNG/JPG/WebP أو دائرة/مستطيل/نجمة. رفع الصور محدود بـ10MB، ويعاد تحجيمها بحد أقصى 2048px محليًا لتقليل الذاكرة. SVG غير مقبول كصورة مستوردة.
3. في 2D: اسحب العنصر، اسحب المربع الصغير لتغيير حجمه، أو عدّل القيم من المفتش. التصميم داخل مربع افتراضي 1024×1024، وليس قياسًا بالسنتيمتر.
4. لكل وجه قائمة طبقات مستقلة (حتى 100 طبقة). القائمة تعرض أعلى طبقة أولًا؛ استخدم الأسهم لتغيير ترتيب التراكب.
5. في 3D: اسحب للدوران ومرّر للتقريب، أو فعّل الدوران التلقائي وأعد ضبط الكاميرا. خريطة الأجزاء أسفل المشهد تتيح التصميم على الأكمام وجانبي الكابيشون أيضًا. طباعة الوجه/الظهر ضمن مساحة مركزية، والأكمام والكابيشون تستخدم إحداثيات UV مستقلة وليست خدمة مطابقة عبر خطوط الخياطة. على سطح المكتب، تظل معاينة 3D وخريطة 2D ظاهرتين في جزأين منفصلين من مساحة العمل.
6. صدّر صورة المجسم بالزاوية الحالية، أو التصميم وحده بخلفية شفافة، بدقة 1024/2048/4096px. تصدير المجسم يحتاج تبويب 3D مفتوحًا وWebGL متاحًا. دقة الصورة بالبكسل؛ لا يدّعي الملف دقة DPI أو اعتمادًا للطباعة.
7. الحفظ التلقائي محلي ويخضع لسعة المتصفح؛ استخدم ملف المشروع JSON لنقل التصميم أو الاحتفاظ بنسخة. الصور مضمّنة بالملف. عند امتلاء التخزين تظهر رسالة واضحة بدل الادعاء بنجاح الحفظ.

**الحدود:** هذه مجسمات عرض وتصوير إجرائية وليست محاكاة نسيج أو باترونات قص وخياطة. لا توجد خدمة تنفيذ طلبات طباعة، ولا اتصال بمتاجر، ويدعم استيراد GLB ذاتي الموارد بشروط UV المذكورة أدناه. راجع مواصفات المطبعة والألوان والمساحة الفعلية قبل الإنتاج. عند غياب WebGL يظل محرر 2D وتصدير التصميم متاحين.

## التحقق

```sh
npm run dev # افتح /product-studio/
npm run lint
npm run test:product-studio
npx playwright install chromium # مرة واحدة على جهاز التطوير
npm run test:product-studio:browser
npx vite build
```

اختبارات المتصفح تشمل WebGL، تغيّر المنتج واللون، الوجه والظهر، وصول الرسم للمجسم، تحرير وسحب وتراجع وقفل وإخفاء وتغيير حجم الطبقات، رفع صورة وتكرارها وترتيبها وحذفها، حفظ وفتح ورفض مشروع غير صالح، الموبايل واللغة والثيم، وحالة غياب WebGL. تُفحص ملفات PNG المنزّلة فعليًا: أبعادها، ألفا الخلفية، ومحتواها غير الفارغ، مع DPR=2 لاكتشاف أخطاء دقة التصدير.

المعاينة لا تعتمد على صور أو نماذج بعيدة أو مفاتيح API. Three.js موجود أصلًا ضمن اعتماديات الموقع.

## التحديث المرجعي

واجهة داكنة افتراضية بخلفية تصوير خضراء وتيشيرت كقطعة البداية. ثنيات السطح إجرائية وليست ناتجة من محاكاة قماش. إعدادات الخامة والإضاءة ووضعية الأكمام وطبقات الأجزاء الستة تُحفظ داخل ملف المشروع، مع ترقية تلقائية للمشاريع القديمة ذات الوجهين. خريطة UV ليست باترون تصنيع، ولا تعرض أبعادًا وهمية بالسنتيمتر.


## المعاينة على شخص 2D

- `sections/TryOnDesk.tsx`: اختيار صورة جاهزة أو رفع صورة شخص، مقارنة الأصل بالنتيجة، ضبط حدود التلوين ومساحة الطباعة، ومقابض سحب الزوايا للتشويه ثنائي الأبعاد.
- `core/tryOn.ts`: إعدادات المعايرة، التحقق من المضلعات، التحويل الشبكي للرسم، تلوين الملابس والحفاظ على إضاءة الصورة الأصلية، وإخراج الصورة النهائية بدون أدلة التحرير.
- `assets/model-man.jpg`: صورة عرض اصطناعية مولّدة بالذكاء الاصطناعي، وليست تصويرًا لمنتج فعلي. أُزيلت صورة البنت وخيارها؛ المشاريع القديمة التي استخدمتها تُحوَّل إلى الإعداد الرجالي الافتراضي دون الاحتفاظ بالصورة القديمة.
- الصور الجاهزة لتيشيرت أمامي؛ تستخدم رسومات الوجه الأمامي فقط. تصدير صورة جاهزة لمنتج مختلف يُمنع برسالة واضحة حتى اختيار تيشيرت أو رفع صورة ملابس مطابقة.
- لصورك: اختر ملابس فاتحة سادة بوضعية أمامية. حرّك نقاط حدود التلوين لتناسب القماش، ثم عدّل زوايا الطباعة. تلبيس 2D هنا تركيب وتلوين على الملابس الموجودة في الصورة، **وليس توليد ملابس جديدة أو تغيير قصتها أو تقدير المقاس أو إزالة الملابس**. لا يوجد كشف جسم تلقائي ولا محاكاة للاحتجاب أو القماش.
- التصدير بنسبة 3:4 وبطول 1024 أو 2048 أو 4096 بكسل؛ الصور الجاهزة بدقة مصدر 1086×1448، لذا الأحجام الأكبر تعيد تحجيم الصورة الأصلية ولا تضيف تفاصيل فوتوغرافية جديدة. الرسم نفسه يُرسم بالدقة المختارة (حتى 2048 لتكسية الصورة).
- ملفات المشاريع تحفظ الصورة المرفوعة ومعايرة القناع والزوايا وقوة التلوين، مع التحقق من الصور المضمنة ورفض الروابط الخارجية وSVG.
- المعالجة محلية بالكامل. استخدم صورًا تملك حق استخدامها، خصوصًا عند مشاركة ملف المشروع الذي يتضمن الصورة.

## تحسينات المعاينة والأدوات

- حواف وأساور التيشيرت أرفع من الهودي، مع خامة نسيج مفلترة بمستويات mipmaps لتقليل التحبّب والتموّج.
- قصة عادية أو واسعة للملابس، وإعدادات قطن/قطن ثقيل/رياضي. القصة تغيير في نسب المجسم، وليست مقاسات خياطة.
- زوايا كاميرا جاهزة أمامية وخلفية وجانبية وثلاثة أرباع، مع إعادة ضبط الكاميرا.
- نسخ التصميم للجزء المقابل بأسماء طبقات مستقلة، مع تأكيد قبل استبدال أي تصميم موجود.

نتيجة التحقق الأخيرة: **28 اختبار منطق + 13 اختبار متصفح**. تشمل الاختبارات الجديدة معايرة الصور والسحب والتراجع، رفع صورة وتخزينها، مقارنة قبل/بعد، تصدير PNG طولي فعلي، القصات وزوايا التصوير ونسخ التصميم.

## العرض المقسوم على نمط استوديو الملابس

التخطيط الافتراضي على سطح المكتب هو **خريطة أجزاء يسارًا، معاينة ثلاثية الأبعاد في الوسط، وأدوات موحّدة يمينًا**. تبويبا التصميم/المشهد ينقلان التمرير إلى مجموعتي الأدوات دون حذف الحقول أو فقد حالتها. يتوفر وضع 3D منفرد، ووضع 2D مع محرر دقيق وخريطة أجزاء، ومعاينة الأشخاص السابقة. على الموبايل تتكدّس المساحات رأسيًا.

- `sections/ToolSidebar.tsx`: شريط أدوات موحّد وتنقل بين التصميم والمشهد.
- `core/flatTee.ts`: نموذج تيشيرت أصلي، بسطح متصل عند الأكتاف وأجزاء مستقلة للتكسية. لا تُستخدم ملفات مجسمات مجهولة الترخيص. سطح الطباعة يتبع نفس دالة الثنيات، بما في ذلك الوجه الخلفي.
- `core/staging.ts`: خلفية استوديو ضبابية مولّدة محليًا، مع خيار خلفية سادة محفوظ في المشروع. عرض الشماعة مُزال. يحسب ضبط الكاميرا مساحة القطعة ونسبة الشاشة لتجنب قص الأكمام.
- تكبير وتصغير خريطة الأجزاء من 60% إلى 200%، مع زر احتواء وتمرير مستقل.
- وضع تركيز اختياري يخفي تنقل الموقع ويقلّص الشريط العلوي لتوسيع مساحة التصميم، مع زر رجوع واضح.

خريطة الأجزاء **UV لتوزيع الرسم وليست باترون قصّ تصنيع**؛ لذلك لا تُعرض قياسات سنتيمترية مختلقة، ولا توجد واجهة inside/outside وهمية. أجزاء التيشيرت المدعومة فعليًا هي الأمام والخلف والكمان، بينما يتضمن الهودي جانبي الكابيشون أيضًا. تحسين المجسم إجرائي وليس مسحًا ثلاثي الأبعاد لقطعة قماش حقيقية.

التحقق: **80 اختبار منطق و32 اختبار متصفح**، بما فيها ترتيب الأعمدة، التكبير والاحتواء، أوضاع العرض والخلفية، وضع التركيز وتغيير حجم العنصر المحدد.

### تصحيح بنية التيشيرت
- التيشيرت المعلّق غلاف قماش أمامي وخلفي بفتحات حقيقية للرقبة والأكمام وأسفل القطعة، بدل إغلاقها بأسطح صلبة.
- التقاء الجانبين والكتفين تدريجي، مع سطح داخلي مستقل غير مطبوع وخياطة رفيعة، وتوزيع محلي للرسم على الكم.
- اختبارات هندسية لأشعة تمر عبر الفتحات، التقاء الخياطة، فصل البطانة وتوزيع رسم الأكمام، واختبار ترحيل المشاريع القديمة بعد إزالة صورة البنت.
- النموذج ما زال إجرائيًا؛ ليس مسحًا فوتوغرافيًا أو محاكاة فيزيائية للقماش.

### تحديد العنصر والتصحيح الجانبي
- الضغط على أي طبقة ظاهرة في خريطة القطعة يحددها وينقل لوحة الأدوات إلى «العنصر المحدد»: نص وخط ولون للنصوص، وأبعاد ودوران وشفافية للطبقات.
- شريط حجم يحافظ على النسب، ومقبض ركن في خريطة 2D لتغيير الحجم بالسحب؛ الطبقات المقفولة لا يمكن تغييرها.
- أُزيل عرض الشماعة وزر تشغيلها. تُقرأ قيمة hanger القديمة للتوافق فقط وتُعطَّل عند تحميل المشروع.
- توحيد عينات الحافة بين السطح والخياطة وتوحيد اتجاه الإضاءة عند التقاء الوجه والظهر يمنع الشقوق والمظهر المسنن على الجنب، مع إبقاء فتحات القماش مفتوحة.

| الصور | `ArtworkTools.tsx` و`core/imageTools.ts`: قص نسبي، سطوع وتباين وتشبع وتدرج لوني، إعادة ضبط وتراجع. إزالة الخلفية **خوارزمية محلية للخلفيات البسيطة المتصلة بالحواف، وليست عزل أشخاص بالذكاء الاصطناعي**. |

| التاريخ | `HistoryPanel.tsx`: استعادة آخر 40 خطوة في الجلسة، إضافة للتراجع والإعادة. النسخ الدائمة تُحفظ يدويًا بالمكتبة. |
| التصوير | `SceneExtras.tsx`: إعدادات إضاءة وخلفية جاهزة، تقريب على منطقة التصميم المركزية وتصدير الأمام والخلف والجنب كملفات PNG منفصلة 2048px. قد يطلب المتصفح السماح بتنزيل عدة ملفات. |

### GLB ومصدر الواقعية
أُضيف **استيراد مجسمات**، وليس ملف مسح احترافي جاهزًا. يظل المجسم الافتراضي الإجرائي مستخدمًا حتى يرفع المستخدم موديلًا مناسبًا ومرخّصًا.

- `core/glb.ts`: GLB 2.0 حتى 20MB و500 ألف رأس، جميع الموارد مضمَّنة. تُرفض الروابط الخارجية والامتدادات المطلوبة والضغط غير المدعوم قبل التحميل.
- يجب وجود شبكتي UV مسمّاتين `front` و`back`، كل منهما بخامة واحدة. يمكن إضافة `leftSleeve` و`rightSleeve` و`hoodLeft` و`hoodRight` للطباعة على الأجزاء الأخرى.
- تُطبّق الخامة/التصميم على UV الجزء كاملًا. يلزم إعداد UV صحيح للملف؛ لا تحويل تلقائي لأي موديل عشوائي، ولا محاكاة سقوط قماش أو إعادة تركيب تلقائي.
- يُضمّن الملف في المشروع لفتح نفس المعاينة لاحقًا. مشاريع كبيرة قد تتجاوز سعة localStorage: تُعرض رسالة فشل الحفظ التلقائي، وتظل المكتبة وملف JSON متاحين. استيراد ملف المشروع حتى 80MB.
- لا يوجد نموذج شخص نسائي ولا شماعة في المشهد، بما في ذلك المشاريع القديمة.

### التحقق
اختبارات المنطق تغطي التحويلات والمحاذاة، حساب السنتيمتر/DPI، سلامة التأثيرات والخطوط، وحظر موارد GLB الخارجية، بالإضافة لاختبارات فتحات المجسم والحفظ السابقة. اختبارات المتصفح تتحقق من الخط المضمّن بعد إعادة التحميل، دوران/حجم العناصر، معالجة الصورة على مستوى البكسل، خروج PNG مستطيل فعلي بالمقاس، المكتبة بعد إعادة التحميل، GLB صناعي اختباري ذي UV وتصديره، انحناء العربية، وتصدير الزوايا الثلاث.

## مراجعة BlankBuilder وتحسين السحب
انظر `REFERENCE-COMPARISON.md` للمصادر، المميزات المضافة، والفروق التي لا يصح الادّعاء بتوفّرها (موديلات مرخصة، باترونات فعلية وخدمات AI/الرندر السحابي).

- `core/measurements.ts` و`SelectionMeasure.tsx` و`MeasurementPanel.tsx`: المقاس الحي بوحدات mm/cm/in. دون مساحة طباعة مدخلة يُعرض px فقط.
- `PatternArtwork.tsx` و`core/artwork.ts`: رسم مستقل مخزّن لكل عنصر؛ الموقع والدوران والشفافية لا يعيدون رسم النص/الفلاتر. ذاكرة Cache محدودة بالبكسلات، ومفتاح الصور لا ينسخ Base64 أثناء الحركة.
- `App.tsx`: تجميع أحدث التعديلات في إطار رسم واحد، تفريغ آخر تحديث قبل إنهاء السحبة، وتجنب التعديلات المتطابقة.
- `Preview3D.tsx`: إعادة استخدام سطح الطباعة وتحديث الجزء المتغيّر فقط، مع وتيرة تكسية محدودة وجودة معاينة مستقلة عن التصدير.
- `core/materials.ts` و`GradientControl.tsx`: تدرجات حتى خمسة ألوان وخامات إجرائية إضافية؛ `core/rasterEffects.ts` للعمليات المحلية المعلنة على الصور.
- `core/production.ts` و`ProductionPanel.tsx`: ZIP بطبعات منفصلة وبيانات pHYs للدقة، وPDF لمخطط الطباعة والقياسات، وJSON. هذا مسار إضافي؛ تصدير الأجزاء الكامل السابق لا يزال متاحًا.
- «نافذة/ستائر/شعاع/قوس» خلفيات مولّدة وليست إسقاط ظلال ضوئية على المجسم. لا يعود خيار الشماعة.

التحقق النهائي لمراجعة المرجع: **65 اختبار منطق، 28 اختبار متصفح، TypeScript وبناء Vite ناجحة**. اختبارات جديدة لحركة متواصلة دون إعادة رسم Raster، تراجع سحبة واحدة، المقاس 260×229 mm والتحويل للوحدات، خامات وتدرج دون أخطاء Shader، قراءة ZIP وPNG pHYs وPDF فعلي، معالجة الصور والتنقل وجودة المعاينة.

## القص التفاعلي ونقاط التدرج وSVG
- `sections/ImageCropDialog.tsx` و`core/crop.ts`: قص بالمقابض/الإطار والكيبورد، معاينة مسودة وإلغاء/تأكيد غير إتلافي، تركيز محصور وإغلاق Escape، ونِسب جاهزة. لا تصل مفاتيح الحذف من النافذة إلى طبقات المشروع.
- `core/materials.ts` و`GradientControl.tsx`: مواقع ألوان مستقلة اختيارية، تحرير مباشر بالنقر والسحب والكيبورد والنسبة، مع توافق التدرجات القديمة. `core/fabric.ts` يمرّر نفس مواقع الألوان إلى Shader القماش.
- `core/vectorTrace.ts` و`VectorTracePanel.tsx`: SVG أحادي اللون بمسارات بكسلية من المصدر المقصوص؛ لا يتضمن Bitmap ولا كودًا/روابط خارجية، وليس تحويلًا ملوّنًا ناعمًا بالذكاء الاصطناعي.

التحقق بعد المراجعة الإضافية: **80 اختبار منطق و32 اختبار متصفح ناجحة**، مع TypeScript وبناء Vite وفحص المسافات. تشمل الاختبارات إلغاء/تطبيق/تراجع القص، عزل مفاتيح النافذة وحصر التركيز، تحرير نقاط التدرج بالسحب والكيبورد وعدم حدوث أخطاء Shader، وصحة SVG وعدم استبدال الأصل.

## مكتبة قصّات التيشيرت
داخل اختيار التيشيرت توجد 7 قصّات بصور مصغّرة: Classic / Boxy / Slim / Longline / Drop shoulder / V-neck / Long sleeve. `core/teeStyles.ts` يحوّل الإحداثيات والـ normals مع إبقاء UVs دون تغيير، وتستخدم الملابس والبطانة والخياطة وطباعة الأمام/الخلف التحويل نفسه. الموضع محفوظ في `appearance.teeStyle` الاختياري، والمشاريع القديمة تظهر بالكلاسيك. التبديل لا يحذف الطبقات ويدعم التراجع والحفظ المحلي. `sections/TeeStylePicker.tsx` قسم مستقل.

الموديلات إجرائية أصلية وليست scans أو محاكاة قماش فيزيائية؛ لا تدعي تطابق مقاسات مصنع. خريطة القطع ما زالت مخطط طباعة تقريبيًا وليست باترون خياطة خاصًا بكل قصة. راجع معايرة مساحة الطباعة قبل الإنتاج، خصوصًا عند تغيير القصة. الموديل GLB المخصص يظل مستقلًا عن قصّات التيشيرت المدمجة.

التحقق بعد إضافة القصّات: **86 اختبار منطق و33 اختبار متصفح** ناجحة، مع TypeScript وبناء Vite وفحص المسافات. فحص بصري للكُم الطويل وV-neck وBoxy في WebGL، واختبار التبديل والحفظ والتراجع وعدم تغيير طبقات التصميم.
