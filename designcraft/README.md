# استوديو التصميم — DesignCraft

استوديو التصميم هو محرّر الجرافيك في UniTool (صفحة `designcraft.html`)، وليس استوديو الشعار أو الفيديو.

## المميزات المضافة

### 1) المحاذاة الذكية Smart Guides
- أثناء سحب عنصر تظهر خطوط إرشادية للمحاذاة مع حواف اللوحة، مركزها، وحواف/مراكز العناصر الأخرى.
- تعمل المحاذاة بإحداثيات التصميم الحقيقية، لذلك تظل دقيقة مع أي مستوى تكبير.
- زر المغناطيس في شريط الأدوات أو شريط التكبير يفعّل/يوقف الخاصية، ويُحفظ الاختيار على الجهاز.
- اضغط باستمرار `Alt` أثناء السحب لتعطيل المحاذاة مؤقتًا دون تغيير الإعداد.
- الخطوط الإرشادية طبقة عرض منفصلة ولا تظهر في PNG/SVG/PDF.

### 2) التجميع وفك التجميع
- حدّد عنصرين أو أكثر ثم جمّعهم في مجموعة واحدة قابلة للتحريك والتكبير.
- فك المجموعة يعيد العناصر مستقلة مع الحفاظ على خصائصها.
- متاح من الشريط العائم فوق العنصر، لوحة الخصائص، القائمة السياقية، أو الاختصارات.
- العناصر المقفلة تمنع التجميع وتظهر رسالة واضحة.
- العملية تُسجّل كخطوة واحدة في التراجع/الإعادة.

| الاختصار | الوظيفة |
|---|---|
| `Ctrl/Cmd + G` | تجميع العناصر المحددة |
| `Ctrl/Cmd + Shift + G` | فك المجموعة |
| `Alt + Drag` | سحب حر بدون محاذاة ذكية |
| `Ctrl/Cmd + Z` | تراجع |
| `Ctrl/Cmd + Shift + Z` | إعادة |
| `Ctrl/Cmd + S` | حفظ المشروع |

### 3) مكتبة ألوان العلامة — ألواني
- تبويب **ألواني** يحفظ حتى 24 لونًا على الجهاز ويشترك بين كل التصميمات.
- أضف لونًا مخصصًا، احفظ لون العنصر المحدد، أو استخرج ألوان التصميم الحالي بضغطة.
- اضغط على لون لتطبيقه على العنصر المحدد (بما فيه عناصر المجموعة)، أو على الخلفية إذا لم يوجد تحديد.
- الصور لا يُعاد تلوينها حتى لا تتشوّه.
- توجد باليتات بداية جاهزة: محيطي، غروب، طبيعي.

### 4) نسخة احتياطية JSON قابلة للتعديل
- من شريط المحرر: **تنزيل نسخة احتياطية قابلة للتعديل** ينتج ملف `.unitool.json`.
- من الشاشة الرئيسية → **مشاريعي** → **استيراد تصميم** لفتح الملف كنسخة جديدة دون استبدال مشاريعك.
- يحتفظ الملف بالطبقات، النصوص، المجموعات، الصور المضمّنة، التدرجات، الأنماط، الأقفال، وبيانات المحرّر.
- الاستيراد يتحقق من الصيغة والإصدار والأبعاد وأنواع الكائنات ومصادر الصور، ويرفض الملفات التالفة أو غير الآمنة.
- الحدود: 12 MB للملف، 2000 كائن، 50 صفحة. الصور ذات الروابط الخارجية تحتاج اتصالًا بالإنترنت عند الفتح؛ الصور المضمّنة تبقى داخل الملف.
- هذه نسخة قابلة للتعديل وليست بديلًا عن تصدير الصور/PDF.

## الحفظ والخصوصية
- المشاريع وألوان العلامة وتفضيل المحاذاة تُحفظ محليًا في المتصفح (localStorage).
- مسح بيانات الموقع أو استخدام جهاز/متصفح آخر لا ينقل هذه البيانات تلقائيًا؛ استخدم النسخة الاحتياطية للنقل أو الأرشفة.
- إذا امتلأت مساحة التخزين يظهر تنبيه واضح بدل رسالة نجاح مضللة، ويُنصح بتنزيل نسخة احتياطية.

## التطوير والاختبار

```bash
npm run dev                    # تشغيل الموقع على المنفذ 3000
npm run lint                   # فحص TypeScript
npm run test:designcraft       # اختبارات الوحدات (node:test + tsx)
npm run test:designcraft:browser  # اختبارات المتصفح (Playwright)
npm run build                  # بناء الإنتاج
```

لاختبارات المتصفح впервые:

```bash
npx playwright install chromium
npm run test:designcraft:browser
```

يمكن تجاوز العنوان أو مسار المتصفح عبر:
- `DESIGNCRAFT_QA_URL`
- `DESIGNCRAFT_CHROMIUM_PATH`

## ملفات رئيسية
- `src/utils/smartGuides.ts` — حساب المحاذاة ورسم الخطوط الإرشادية.
- `src/utils/editorTools.ts` — التجميع/فك التجميع وتطبيق ألوان العلامة.
- `src/utils/brandKit.ts` — تطبيع الألوان، الدمج، والاستخراج.
- `src/utils/projectFile.ts` — إنشاء/التحقق/استيراد النسخ الاحتياطية.
- `src/components/Editor/Sidebar/BrandKitTab.tsx` — واجهة مكتبة الألوان.
- `tests/studio-tools.test.ts` و`tests/browser/studio-tools.spec.ts` — الاختبارات.
