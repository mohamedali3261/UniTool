# Font Lab — معمل الخطوط

استوديو تصميم وتحرير الخطوط العربية واللاتينية داخل UniTool. يعمل بالكامل في
المتصفح على منحنيات حقيقية من ملفات TTF/OTF (بدون محاكاة)، ويُصدِّر خطاً صالحاً
يُعيد المتصفح قراءته.

## البنية — كل صفحة في مجلد، وكل قسم في ملف

```

├─ index.html              ← نقطة الدخول (dir=rtl)

├─ App.tsx                 ← الهيكل فقط: يربط الأقسام ويوزّع الحالة
├─ core/                   ← المنطق النقي (بدون React)
│  ├─ fontEngine.ts        قراءة الخط، المنحنيات، الملخص والجداول
│  ├─ glyphIndex.ts        فهرس الحروف + أشكال الاتصال من GSUB
│  ├─ outline.ts           أوامر المسارات وعمليات النقاط (تبسيط/محاذاة/حذف)
│  ├─ geometry.ts          تحويلات، تحديد باللاسو، أشكال جاهزة
│  ├─ history.ts           تراجع/إعادة بوسوم ثنائية اللغة
│  ├─ project.ts           مستند المشروع (تعديلات فقط) + الحفظ المحلي

│  ├─ inspector/           مفتش الحرف والنقاط المحددة
│  ├─ library/             مكتبة الخطوط وتحليل الخط

│  ├─ shapes/              الأشكال الجاهزة والعمليات المنطقية

│  ├─ export/              التصدير
│  ├─ history/             سجل التعديلات
│  ├─ projects/            المشاريع المحلية وملف JSON
```

## التشغيل والتحقق

```bash
npm run dev -- --strictPort        # ثم افتح /font-lab/
npm run test:font-lab              # 53 اختباراً: المحرك + الواجهة + الربط
npm run test:font-lab:browser      # Playwright (يحتاج متصفحات مثبّتة)
npm run lint                       # tsc --noEmit
```

## ما يميزه عن أي أداة مشابهة

- **منحنيات حقيقية**: كل نقطة تُحرَّر هي نقطة من glyf، والتصدير يُعيد كتابة
  `glyf`/`loca`/`hmtx`/`head` فقط ويترك `GSUB` و`GPOS` و`cmap` والأسماء كما هي —
  لذلك يبقى اتصال العربية والكرننغ يعمل في الملف المُصدَّر.
- **أشكال الاتصال من الجدول**: الأشكال الابتدائية/الوسطية/النهائية تُقرأ من GSUB،
  لا من أسماء الحروف.
- **معاينة = الملف**: النص يُعرض بالخط الذي ستُصدّره عبر `FontFace`، لا بصورة.
- **تحقق فعلي**: لوحة الفحص تقرأ جداول الخط وتُظهر ما يعمل فعلاً بدل نصوص ثابتة.
- **رسائل ثنائية اللغة** لكل خطأ (مثل ملفات WOFF2 غير المدعومة).
